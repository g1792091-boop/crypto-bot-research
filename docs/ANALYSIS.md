# 레퍼런스 사이트 분석 & 설계 결정

> 작성 환경 메모: 이 저장소를 만든 클라우드 샌드박스에서는 `heyastral.ai`, `helloquant.io`,
> `docs.coinglass.com`, 바이낸스·CoinGecko API가 네트워크 정책으로 차단되어 있었다.
> 그래서 두 사이트는 공개 검색 결과, 공식 소개 문구, 그리고 이 세션에 연결된 Astral MCP 커넥터의
> 도구 목록을 근거로 분석했다. 링크된 `/terminal/session-…` 페이지는 로그인한 사용자의 개인 채팅
> 세션이라 외부에서는 내용을 볼 수 없다.

## 1. Astral (heyastral.ai) — "AI 트레이딩 워크스테이션"

**한 줄 요약:** 대화로 전략을 만들고 → 같은 화면에서 백테스트 카드로 검증하고 → 브로커에 배포해 자동 운용하는 SaaS ($30/월).

| 구성 요소 | 내용 |
|---|---|
| 터미널 (대화형 세션) | `/terminal/session-<id>` 가 한 대화 = 한 작업 공간. 자연어로 요청하면 결과가 "카드"(차트, 백테스트, 주문 미리보기)로 대화 안에 렌더링됨 |
| 전략 빌더 | Astral이 질문을 되물어가며 진입·청산·포지션 크기·리스크를 **사람이 읽고 고칠 수 있는 전략 정의**로 작성. 백테스트와 같은 편집기에 있음 |
| 백테스트 카드 | 자본 곡선, 수익률, 최대 낙폭, 샤프, 거래 통계 |
| 배포/운용 | 브로커 계좌 연결 → 전략 배포 → 대시보드에서 워치리스트, 알림, 체결, 전략 상태 모니터링 |
| MCP 엔드포인트 | ChatGPT/Claude/Cursor 등 외부 AI 클라이언트에서 같은 기능을 도구로 호출 |
| 리서치 | 주식 스크리너, 재무제표, SEC 공시 등. **주식 중심**이며 코인 선물 파생 데이터(펀딩비·OI·청산)는 핵심이 아님 |

MCP 커넥터가 노출하는 도구 이름(`strategy_build`, `backtest_start/status/get`, `equity_curve`,
`strategy_deploy_preview` → `strategy_deploy`, `order_preview` → `order_submit`, `explore_search`,
`notification_profile_*` 등)에서 워크플로가 그대로 드러난다.

1. 자연어 → **구조화된 전략 객체**
2. 비동기 백테스트 (시작 → 상태 폴링 → 결과)
3. 배포와 주문은 항상 **미리보기 → 확인** 2단계
4. 알림 프로필로 이벤트 푸시

**가져올 점:** 자연어 → 편집 가능한 전략 JSON, 백테스트를 전략 편집기 옆에 두기, 실행 전 미리보기 단계, 같은 기능을 API와 에이전트 도구로 노출하기.
**우리와 다른 점:** 우리는 코인 무기한 선물이 대상이다. 그래서 레버리지, 강제청산, 펀딩비, OI, 롱숏비율을 백테스트와 에이전트 판단에 넣어야 한다.

## 2. HelloQuant Pro Trading Suite (helloquant.io/protradingsuite/trade)

**한 줄 요약:** 한국 1인 개발자(유튜브 "김삘롱")가 만든 멀티 거래소 코인 자동매매 터미널.

| 구성 요소 | 내용 |
|---|---|
| 트레이드 화면 | 차트 + 주문 패널 + 포지션/계좌. 바이낸스·OKX·바이비트·비트겟·BingX 등 여러 거래소 API 키 연동 |
| 전용 서버 | 사용자마다 격리된 서버에서 봇을 24시간 운용 (API 키 보안) |
| 전략 기능 | 추세 필터(횡보장 진입 억제), 손절 후 추세 방향으로 전환하는 로직 등 |
| DemoTradingSuite | 코인·선물 **페이퍼 트레이딩** 버전 |
| 성격 | 비수탁형(non-custodial) 개인용 도구, 커뮤니티 채팅방 운영 |

**가져올 점:** 한 화면에 차트, 주문, 계좌를 두는 트레이드 레이아웃, 데모 계좌, 반대 신호 스위칭(우리 DSL의 `allow_reverse`).

## 4. 꼭 알아야 할 외부 서비스 제약

### 제약 1 — CoinGlass는 "차트를 가져다 붙이는" 방식이 안 된다
- 공식 임베드(iframe) 위젯이 없다. 사이트를 iframe으로 넣으면 이용약관 문제가 생기고 보통 차단된다.
- 정식 경로는 **유료 API** (Hobbyist $29/월 · 분당 30회 / Startup $79 / **Standard $299 부터 상업적 이용**).
  사이트를 공개 서비스로 운영하려면 Standard 이상이 필요할 수 있으니 약관을 확인해야 한다.
- 그래서 이 프로젝트는 **CoinGlass 데이터를 받아 우리 차트에 그린다.** 키가 없으면 바이낸스 공개
  선물 API(OI 히스토리, 펀딩비, 롱숏 계정비율)로 자동 대체된다. 청산 히트맵은 CoinGlass 키가 필요하다.
- 엔드포인트 경로는 `coinglass.py`의 `ENDPOINTS` 한 곳에 모아 두었다(문서 개편 대비).

### 제약 2 — TradingView 지표 "값"은 밖으로 꺼낼 수 없다
| 제품 | 비용 | 지표 | 우리 용도 |
|---|---|---|---|
| 위젯 (Advanced Chart 등) | 무료 | 내장 지표 표시 가능, **값 추출 불가** | 사용자가 지표를 조합해 보는 화면 |
| Lightweight Charts | 무료 (Apache-2.0) | 없음 (직접 계산) | 백테스트 결과, OI·펀딩 패널 |
| Advanced Charts / Trading Platform 라이브러리 | 무료지만 **회사·공개 웹 프로젝트만 신청 가능** (개인·학습용 불가) | 내장 | 추후 사업화하면 검토 |

Pine Script는 TradingView 밖에서 실행할 수 없다. 그래서 백테스트와 페이퍼 트레이딩은
`backend/app/indicators.py`에서 **Pine `ta.*`와 같은 공식**으로 지표를 계산한다
(EMA·RMA의 SMA 시드, RSI·ATR의 Wilder 스무딩, BB의 모집단 표준편차, `ta.supertrend` 밴드 규칙).
화면의 TradingView 지표와 백테스트 신호가 같은 기준을 쓴다는 뜻이다.
"TV 차트에 지표 표시" 버튼은 전략 JSON의 지표를 TradingView 위젯 스터디로 매핑한다.

### 제약 3 — 바이낸스 선물 API 지역 제한
`fapi.binance.com`은 미국 등 일부 지역 IP에서 451로 막힌다. 서버를 한국, 싱가포르, 일본 리전에 두거나
Bybit·OKX 어댑터를 추가해야 한다. 네트워크가 막히면 `DATA_SOURCE=auto`가 합성 데이터로 대체하고,
화면에 **"synthetic (실데이터 아님)"** 배지를 띄운다.

## 5. 백테스트 체결 규칙 (신뢰도를 위한 가정)

- 신호는 봉 **마감** 기준으로 판단하고 **다음 봉 시가**에 체결한다 (룩어헤드 방지).
- 손절·익절·추적손절·강제청산은 봉의 고가와 저가로 판정한다. 같은 봉에서 둘 다 닿으면 **손절 먼저**(보수적).
- 격리 마진, 유지증거금률 0.5%로 청산가를 계산하고, 청산되면 증거금 전액을 잃는다.
- 편도 수수료 0.04%와 슬리피지 0.01%를 적용하고, 가정 펀딩비 0.01%/8h를 보유 시간에 비례해 부과한다.
- 페이퍼 봇도 같은 `Simulator`를 쓴다. 봉 마감 신호는 현재가로 체결하고, 손절과 익절은 폴링마다 실시간 가격으로 확인한다.
