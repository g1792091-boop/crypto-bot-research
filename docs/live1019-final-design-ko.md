# 10/19 실거래 봇 최종 설계: 바이비트 봇 · MEXC 봇

두 분이 고르신 최종 구성 기준입니다. 숫자는 2020-01~2026-09 백테스트, 실거래 규칙(주말 쉼, 발표 30분 금지)을 넣은 값입니다.

거래 하나 따라가기, 매매법별 진입·커스텀값·손절, 커스텀값 흔들기 시험은 [봇 이해하기](live1019-bot-guide-ko.md)에 있습니다.

## 1. 한눈에 보기

```
 규칙봇(paperbot-live3)        ← 바이낸스 1분봉을 받아 둠
        │ 1분봉
        ▼
 합친 봇 페이퍼 "A+C 합본"     ← 매매법 32개 · 세팅 101개 · 가상 계좌 1개 (항상 거래)
 (paperbot-combo, combo.json = combo.live-ac.json, DB live-ac.db)
        │ 같은 페이퍼 계좌(COMBO@mix)를 두 실행기가 따라감
   ┌────┴─────────────────────┐
   ▼                          ▼
 바이비트 실행기               MEXC 실행기
 $100 · 신호등 20번 중 17승    $100 · 신호등 20번 중 18승
 (공격형)                      (안전형)
```

- 봇의 두뇌(언제, 어떤 코인을, 어느 방향으로, 어디서 손절·익절할지)는 **페이퍼 봇 하나**입니다.
- 두 실행기는 그 페이퍼 봇을 각자 거래소에서 따라 합니다. 차이는 **수수료와 신호등 기준**뿐입니다.

## 2. 고정 규칙 (두 봇 공통)

| 항목 | 값 |
|---|---|
| 코인 | BTC, ETH, SOL, DOGE, LTC, BCH (USDT 무기한 선물) |
| 배수 | BTC 40배, 나머지 30배 (격리, 단방향) |
| 증거금 | 계좌의 40% |
| 포지션 | 한 번에 하나 |
| 주문 | 시장가 진입, 손절은 거래소에 걸어 둠 |
| 쉬는 시간 | 한국 시간 토·일 새 진입 없음. 미국 발표(CPI·고용·FOMC·PCE) 앞뒤 30분 새 진입 없음 |
| 익절 | 계단식: 순ROE 11%에서 10% 잠금, 이후 3%씩 |
| 손실 한도 | 한 번 손절로 계좌의 35% 넘게 잃지 않게 크기를 줄임. 손절이 강제청산 가격 안쪽에 못 들어가면 진입하지 않음 |

## 3. 진입 과정 (순서대로)

1. **신호:** 32개 매매법이 각자 자기 봉(15분·30분·1시간)이 닫힐 때 신호를 냅니다.
2. **세팅 조건:** 세팅마다 따로 정한 조건을 봅니다.
   - 방향 반대로: 25개 세팅은 매매법 신호와 **반대 방향**으로 들어갑니다. 백테스트에서 반대가 맞았던 세팅입니다.
   - 진입 조건: 24시간 모멘텀, 펀딩, 세션, 변동성, BTC 상태 같은 조건이 맞을 때만 들어갑니다.
   - 신호봉 크기: 18개 세팅은 신호봉이 일정 ATR 이상(또는 이하)일 때만 들어갑니다.
3. **끄기 구간:** 세팅마다 과거에 졌던 구간에서는 진입하지 않습니다. 한국 시각, 코인×방향, 요일, 장세×방향, 미결제약정, 7일 위치 등입니다.
4. **진입 방식:**
   - 즉시(68개 세팅): 신호봉이 닫힌 다음 분에 시장가로 들어갑니다.
   - 돌파 확인(33개 세팅): 다음 봉 안에 가격이 신호봉의 고가(롱)·저가(숏)를 넘을 때 시장가로 들어갑니다. 못 넘으면 취소합니다.
5. **주말·발표 확인:** 한국 시간 주말이거나 발표 앞뒤 30분이면 들어가지 않습니다.
6. **한 포지션:** 이미 포지션이 있으면 새 신호는 건너뜁니다. 같은 분에 신호가 여럿이면 설정 목록 순서가 앞선 것을 택합니다(A 세팅이 먼저, C 세팅이 다음).
7. **손절 확인:** 손절 가격이 강제청산 가격 안쪽에 들어가지 않으면 진입하지 않습니다("손절 규칙으로 거절").
8. **실거래 따라가기:** 페이퍼 봇이 들어가면 두 실행기가 시장가로 따라 들어가고, 곧바로 거래소에 손절 주문을 겁니다. 이때 각 실행기는 먼저 신호등을 봅니다(7장).

## 4. 손절 구조

세팅마다 손절 방식이 정해져 있습니다.

| 손절 방식 | 뜻 | 세팅 수 |
|---|---|---|
| ATR 3배 | 신호봉 ATR(14)의 3배 거리 | 31 |
| ATR 2배 | ATR의 2배 | 10 |
| ATR 1.5배 | ATR의 1.5배 | 7 |
| ATR 4배 | ATR의 4배 | 6 |
| ATR 1배 | ATR의 1배 | 2 |
| 스윙 10봉 | 직전 10봉의 최저가(롱)·최고가(숏) 바깥 + 가격 0.1% (최소 0.3%) | 16 |
| 스윙 20봉 | 직전 20봉 기준, 같은 방식 | 9 |
| 스윙 5봉 | 직전 5봉 기준, 같은 방식 | 5 |
| 고정 2% | 진입가에서 2% | 15 |

- 손절 주문은 **거래소에 걸려 있어서** 서버나 실행기가 꺼져도 남아 있습니다.
- 손절이 너무 멀어 강제청산보다 바깥이면 진입하지 않습니다. 한 번 손절로 계좌의 35%를 넘게 잃을 크기면 크기를 줄입니다.
- 백테스트 평균 손실은 ROE −38% 안팎입니다(수수료·슬리피지 포함). 계좌 기준으로는 약 −15%입니다.
- 손절 거리를 ±20% 바꿔 보는 시험에서 지금 설정이 안정적이었습니다(좁히면 나빠지고 넓혀도 비슷함).

## 5. 익절 구조 (계단식 잠금)

익절 목표가 따로 없고, 수익이 나면 **손절선을 수익 쪽으로 계단처럼 올려 잠급니다.** 청산은 손절선에 닿을 때만 일어납니다.

| 그동안 가장 높았던 순ROE (수수료 뺀 값) | 손절선(잠금)이 놓이는 곳 |
|---|---|
| 11% 미만 | 처음 손절 그대로 |
| 11% 도달 | +10% (본전 위로 잠금) |
| 14% 도달 | +13% |
| 17% 도달 | +16% |
| … 3%마다 | 잠금도 3%씩 올라감 |

- 순ROE 11%는 가격으로 BTC(40배) 약 0.39%, 알트(30배) 약 0.48% 움직임입니다(수수료 포함).
- 한 번 11%에 닿으면 그 거래는 최소 +10%로 끝납니다. 대부분의 이긴 거래가 +10~13%에서 끝나고(평균 이익 ROE +12.8%), 가끔 크게 이어지는 거래가 더 큰 이익을 냅니다.
- 실행기는 페이퍼 봇이 잠금을 올릴 때마다 **새 손절을 먼저 걸고, 걸린 것을 확인한 뒤 옛 손절을 지웁니다.** 손절이 비는 순간이 없습니다.

## 7. 바이비트 봇 vs MEXC 봇

| | 바이비트 봇 | MEXC 봇 |
|---|---|---|
| 따라가는 봇 | A+C 합본 페이퍼 (같음) | A+C 합본 페이퍼 (같음) |
| 금액 | $100 (페이퍼 $1,000의 0.1배 크기) | $100 (같음) |
| 수수료 (테이커) | 0.055% | API 0.08% |
| 손절 주문 | 거래소 조건부 손절(축소 전용) | 거래소 계획 주문(마지막 체결가 기준, 7일 만료 전에 다시 검) |
| 신호등 | 최근 20번 중 17승(85%) 이상일 때만 진입 = 공격형 | 최근 20번 중 18승(90%) 이상일 때만 진입 = 안전형 |
| 백테스트 월 중간값 (2020~24 / 2025~26) | x5.5 / x7.3 | x2.2 / x5.2 |
| 하루 진입 (평일) | 약 2.8번 | 약 2~2.6번 |
| 봇이 안 맞을 때 (처음 보는 기간 추정) | 월 x0.65 | 월 x1.00 (본전 근처) |
