## 1. 이 보고서에서 쓰는 말

| 말 | 뜻 |
|---|---|
| **R** | 처음 손절까지 잃는 금액을 1로 본 단위. +0.5R = 손절 폭의 절반만큼 이익 |
| **ROE** | 증거금 대비 수익률. 30배에서 가격 1% = ROE 30% |
| **ATR** | 최근 봉들의 평균 움직임 폭. 2 ATR 손절 = 평균 움직임 2배 떨어진 곳에 손절 |
| **bp** | 0.01%. 10bp = 0.1% |
| **가운데값** | 결과를 줄 세웠을 때 한가운데 값(평균보다 극단값에 덜 흔들림) |
| **p** | 운만으로 이만큼 좋은 결과가 나올 확률. 작을수록 운이 아닐 가능성 |
| **동전 던지기 계좌(RANDOM)** | 같은 시각·같은 코인에서 방향만 무작위로 정하는 페이퍼 계좌. 이것보다 나아야 실력 |
| **방향 뒤집기** | 같은 신호를 반대 방향으로 들어갔다면 어땠을지 계산. 비슷하면 방향 실력이 없는 것 |
| **청산 / 강제청산** | 청산 = 포지션을 닫는 것(손절·익절). 강제청산 = 증거금이 바닥나 거래소가 닫는 것 |
| **신호 전체 다시 돌리기** | 계좌가 실제로 잡은 거래만이 아니라, 나온 모든 신호를 하나씩 같은 조건으로 계산한 것 |

## 3. 익절·손절·배수 기준 (한곳에 정리)

**손절**
- 진입 때 2 × ATR(14). N09_ALLIG_AROON@1h는 보통 가격의 약 1.35~1.5%, 최대 약 2.8%입니다.
- 실거래 손절가는 실제 체결가 × (페이퍼 손절 ÷ 페이퍼 진입)으로 정해지고, 페이퍼보다 넓어지지 않습니다.

**익절**
- 고정 익절 주문은 없습니다. 계단(사다리) 방식입니다.
  - 순ROE +12% → +10% 잠금
  - +17% → +15% 잠금
  - +22% → +20% 잠금 … 5%p씩 올라갑니다.
- 실거래 손절은 페이퍼 계단을 약 15초 안에 따라 올라갑니다.
- 바이낸스 앱의 ROE는 20배라서 페이퍼(대부분 30배)의 약 2/3로 보입니다(+12% → 약 +8%). 비교는 가격과 달러로 하세요.

**본전 승률**
- 1시간봉 계단 방식의 본전 승률은 약 75%입니다.
- $400 진입 기준 이기면 평균 약 +$2.2, 지면 약 -$5.4입니다.
- 예: N09는 10번 중 8번 이겼는데도 -$26입니다.

- 수익 순위로 고르지 않았습니다. 기준은 결과를 계산하기 전에 고정했습니다(2026-10-17 00:49 UTC, 해시 기록).
  - 실행기가 따라갈 수 있는 기본 매매법 계좌
  - 1시간봉
  - 5년 비용 전 수익이 0 이상
  - 하락장·운 표시가 붙은 계좌 제외
  - 하루 0.5~2번 거래
  - 20배에서 진입 거절 25% 이하
  - 수수료 비중이 작은 순서, 같은 봉 겹침이 적은 순서
- 알려 드릴 점이 세 가지 있습니다.
  1. 기준을 쓰기 전에 분석 결과 일부를 이미 본 상태였습니다.
  2. "운 의심" 기준이 페이퍼에서 번 계좌를 모두 뺐습니다(번 계좌는 거의 다 하락장 덕). 그래서 후보는 전부 손실 중인 계좌입니다.
  3. 1시간봉은 모든 기준을 통과한 계좌가 0개였습니다. 그래서 미리 정한 순서대로 기준 하나(5년 비용 후 마이너스 제외)를 뺐습니다.
- 페이퍼 성적(참고만, 선정에는 쓰지 않음): 10거래, -$26, 승률 80%.

**매매법 설명** (차트로 확인할 수 있습니다)
- 1시간봉 종가의 5·8·13봉 단순이동평균과 Aroon(25)을 씁니다.
- **롱:** 아래 조건을 모두 만족하면 들어갑니다.
  - 5선이 8선과 13선 위에 있음

  - 이 두 사건 중 하나는 지금 봉에서 일어남
- **숏:** 롱의 반대입니다.
- **참고:**

### 4-3. 실행기 설정 (코드로 한 줄씩 확인한 값)

`/etc/paperbot/executor.json` (실거래용):
```json

  "account": "N09_ALLIG_AROON@1h",
  "paper_db": "/var/lib/paperbot/paper3.db",
  "db": "/var/lib/paperbot/exec/executor.db",
  "budget_usd": 100,

  "stop_from": "ratio",
  "risk": {
    "daily_max_loss_usd": 10,
```

| 설정 | 계획 | 권장 | 이유 |
|---|---|---|---|
| `account` | 미정 | `N09_ALLIG_AROON@1h` | 4-2 |
| `budget_usd` | 100 | **100** | 실거래 크기에는 영향이 없습니다. 지갑이 $120을 넘으면 시작을 거부하는 안전장치라 100이 가장 엄격합니다 |
| `qty_scale` | 0.02 | **100 ÷ (10/19 아침 그 계좌의 페이퍼 지갑)** | 실거래 크기 = 페이퍼 수량 × 이 값. 10/16 기준 지갑 $4,974 → 0.0201. 0.015~0.03은 사실상 같습니다 |
| `entry_source` | signal | **paper** | 1시간봉에서는 비용 차이가 없습니다(16.3 vs 16.5bp). signal 쪽은 조건이 더 많습니다 |
| `max_notional_usd` | 800 | **400** | 이 값이 실제 크기를 정합니다. $800은 계좌의 8배, $400은 4배. 1시간봉 손절 한 번이 보통 약 $11 → 약 $5.5로 줄어듭니다(최대 약 $11, 그 이상은 하루 한도가 줄임) |
| `daily_max_loss_usd` | 20 | **10** | 대부분 "오늘 남은 한도만큼 크기를 줄이는" 브레이크로 작동합니다. 드물게 멈추면 다음 날에도 직접 풀어야 합니다 |
| `max_drawdown_pct` | 0.4 | **0.3** | $100이면 $70에서 멈춥니다. 최고점이 오르면 그 70%에서 멈춥니다 |
| `max_consecutive_losses` | 4 | **6** | 136개 계좌 11일 합계로 4는 82번, 6은 24번 멈췄습니다(계좌 하나당 약 0.6번 vs 0.2번). 손실 차이는 거의 없습니다. 1시간봉 한 계좌에서 6연패는 한 달 1% 안팎입니다 |
| `max_leverage` | 20 | 20 | 증거금만 바꿉니다. $400 · 20배 · 격리에서 강제청산까지 4.3~4.6%, 1시간봉 손절은 최대 2.8% → 강제청산 전에 반드시 손절됩니다 |
