# 좋은 수치 찾기 (분석 탭)

들어갈 때 시장 숫자(RSI, 변동성, 추세 세기 등)가 어느 구간이었을 때 결과가 좋았는지 보는 화면입니다. **설명용이고 판정이 아닙니다.** 결과를 보고 나서 좋은 구간을 고르면 과거에만 맞는 구간을 고르게 됩니다(과적합). 36개 매매법도 같은 5년 자료로 골랐습니다. 이 화면 때문에 잠긴 규칙은 바뀌지 않습니다.

## 보는 숫자 (신호 봉이 닫힐 때, 그 봉과 앞 봉만 씀)

| 숫자 | 뜻 |
|---|---|
| RSI(14), 진입 방향 기준 | 숏은 100−RSI로 읽음. 높을수록 들어가는 방향으로 이미 많이 간 상태 |
| ATR% | 봉 하나의 평균 움직임 ÷ 가격 |
| ADX(14) | 방향 없는 추세 세기 |
| EMA200 거리 (ATR 몇 개), 진입 방향 기준 | + = 이미 들어가는 방향 쪽에 있음 |
| 거래량 ÷ 앞 20봉 평균 | 1 = 평소만큼 |
| 볼린저 밴드(20, 2) 폭 | 위아래 폭 ÷ 가운데 (%) |
| 펀딩비 | 진입 전 9시간 안의 마지막 정산 (음수 / 0~0.01% / 0.01% 넘음) |
| 시간대 | 한국 시간 아시아 09~16 · 유럽 16~22 · 미국 22~05 · 새벽 05~09 |

지표 계산은 매매법 자신이 쓰는 잠긴 지표 코드(`third_party/sweep`, `paperbot/sweepsig.lib().fg`)를 그대로 씁니다.

## 5년 계산 (한 번 돌려서 결과 파일을 커밋)

- 거래: 기존 36개 매매법이 15분·30분·1시간·4시간봉, 코인 6개에서 2021-08-01부터 낸 모든 신호를 한 번씩 거래. 청산은 실험과 같음(다음 봉 시가 진입, 2 ATR 손절, 계단 잠금, 수수료·펀딩·강제청산). `paperbot/agents/labtests.signal_outcomes`를 그대로 씀. 모두 1,890,071건.
- R = 처음 손절 거리 한 번만큼 (배수와 상관없이 비교하려고 R로 검사).
- 칸: 숫자마다 봉 길이별로 36개 모두의 진입을 다섯으로 똑같이 나눈 경계 (펀딩비 세 칸, 시간대 네 칸). 모든 매매법이 같은 경계.
- 비교: 한 칸의 평균 R − 같은 매매법의 나머지 진입 평균 R. 양쪽 30건 이상일 때만 검사, 같은 주(월요일 00:00 UTC)의 진입은 묶어서 계산.
- 여러 번 본 것 감안: 검사한 1,241칸 모두를 한꺼번에 Benjamini-Hochberg 5%. 그리고 2021.8~2022 · 2023~2024 · 2025~2026.9 세 기간 모두 같은 방향(각 기간 양쪽 10건 이상).
- **첫 실행 뒤에 더한 규칙:** 거래가 많아 0.02R 같은 작은 차이도 검사를 넘어서, 표시는 차이 0.05R 이상만 합니다 (검사는 넘었지만 작은 118칸은 '차이 없음').
- 결과: 211칸 표시 (더 좋음 127 · 더 나쁨 84).

다시 만들기 (연구실 5년 신호 저장본과 펀딩 기록이 있는 곳에서):

```bash
python -m paperbot.dash.tools.indranges --signals <sig_*.npz 폴더> --funding <펀딩 csv 폴더> \
    --out paperbot/dash/data/indranges.json --work <중간 저장 폴더>
```

30초쯤 걸립니다. 대시보드는 이 파일만 읽습니다 (`/api/v4/indranges`).

## 지금 실험

실험 시작부터 끝난 기존 36 거래를 같은 경계로 나눠 5년 숫자 옆에 둡니다. 진입 봉의 시세는 시장 기록기(market.db 5분봉)에서, 없으면 대시보드의 바이낸스 봉에서 가져옵니다. 거래 100건이 쌓이기 전에는 채워지는 막대만 보입니다. 아직 검사는 하지 않습니다.

매매법별 카드에서도 고른 매매법의 지금 실험 진입을 같은 칸으로 나눠 그 매매법의 5년 평균 옆에 둡니다. 그 매매법의 끝난 거래가 30건 되기 전에는 채워지는 막대만 보입니다.

## 같은 묶음의 다른 화면 (분석 탭)

- **강제청산 직후**: 큰 강제청산(그 코인 1분 금액이 지금까지 기록 전체의 상위 5%, 진입 순간과 같은 기준; 기록이 쌓이면 기준도 바뀜) 뒤 5·15·60분 안의 진입을 청산당한 쪽과 같은 방향 / 반대 방향으로 나눠, 그 밖의 진입·동전 봇과 나란히. 기록기는 10/06 고친 뒤부터 기록했으므로 '기록 시작' 시각을 늘 보여 줍니다.
- **들고 있었다면**: 묶음 수익률 옆에 코인 6개를 1배로 그냥 들고 있었다면, 그리고 끝난 거래를 거꾸로 했다면(같은 때 들어가고 나와 방향만 반대, 수수료는 거꾸로 한 거래도 냄; 손절·익절 자리가 달랐을 것이라 대충 계산). 거꾸로는 계좌마다 거꾸로 계좌를 하나씩 따로 굴립니다: 거래 크기는 그때 거꾸로 계좌가 가진 돈에 맞추고(진짜 계좌와 같은 비율), 가진 돈보다 더 잃지 않으며, 파산선 아래로 떨어지면 거기서 멈춥니다. 같은 크기로 그냥 더하면 한 계좌가 가진 돈보다 더 잃는 숫자(예: −178%)가 나와서 그렇게 하지 않습니다.
- **GH Coin 방향**: 진입 전 24시간 안 GH Coin의 마지막 타점과 같은 방향 / 반대 / 타점 없음. 진입과 같은 시각(같은 봉 마감)에 난 타점은 진입 뒤에 기록되므로 뺍니다. GH Coin 기록기가 돌 때만 보입니다.
