## 지금 도는 것: 관찰 목록 38개 (2026-10-11 두 분 결정)

백테스트를 통과한 커스텀값이 0개라서, **관찰 후보 16개 매매법의 커스텀값 38개**를 돌립니다(`ANALYSIS_KO.md` 8장,
`research/fullgrid/diag/watch_sel.json`). 통과한 값이 아니라 **앞으로의 성적으로 확인하려는 값**입니다.

커스텀값 하나마다 계좌 5개를 같은 신호, 같은 엔진으로 나란히 돌립니다.

| 계좌 | 숫자 | 익절·손절 | 크기 | 무엇을 보나 |
|---|---|---|---|---|
| 후보 | 커스텀값 | 커스텀값의 것 | 규칙봇과 같음 | 커스텀값이 버는가 |
| 1/4 크기 | 커스텀값 | 커스텀값의 것 | 증거금 1/4 | 크기를 줄이면 계좌가 덜 흔들리는가 |

  거래가 300번 이상이면 통과입니다. 통과한 묶음의 통과한 매매법만, 1/4 크기 이하·잃어도 되는 금액으로 실거래를 **두 분이**

- 규칙봇 서버에 **손님으로** 설치합니다. 따로 사용자(`candleague`), 따로 폴더(`/opt/candleague`, `/var/lib/candleague`)를
  쓰고, CPU는 한 개의 30%, 메모리는 1.3 GB(대시보드 0.3 GB)까지만 쓰도록 묶여 있습니다. 규칙봇·데모 랩 파일은 읽지도 못하게
  막아 두었습니다(텔레그램 설정을 옮길 때 데모 랩 설정 파일을 한 번 읽는 것만 예외).
- 설치 스크립트가 먼저 남은 메모리를 봅니다. 2 GB보다 적으면 규칙봇 30일 판정에 영향이 없도록 **멈추고** 알려 줍니다.
- 기록(`league.db`)이 사라져도 걱정 없습니다. 10월 1일부터 다시 계산하면 똑같이 복구됩니다(같은 공개 시세, 같은 규칙).

### 설치 순서 (후보 목록이 올라간 뒤, 규칙봇 서버에서 10~15분)

1. **설치** (규칙봇 서버에 접속해서 한 줄):
   ```bash
   cd /root/crypto-bot-research && git pull && sudo bash deploy/candleague/install_candleague.sh
   ```
   끝에 `엔진: 켜짐`, `감시: 10분마다`가 보이면 됩니다. 처음에는 10월 1일부터 따라잡느라 1시간 안팎 걸립니다(CPU를 30%만
   쓰도록 묶어 두어서). 다 따라잡은 뒤에는 5분마다 몇 초씩만 씁니다.
2. **텔레그램과 대시보드 설정** (한 줄, 비밀번호만 두 번 입력):
   ```bash
   sudo bash /root/crypto-bot-research/deploy/candleague/setup_env.sh
   ```
   - 텔레그램: 데모 랩 봇의 토큰과 받는 사람을 **서버 안에서** 옮겨 넣습니다. 새 키를 만들거나 채팅에 붙일 일이 없고,
     값은 화면에도 나오지 않습니다. 후보 리그 메시지는 같은 대화방에 오고, 첫 줄 제목에 **후보 리그**가 들어 있습니다 (예: `📊 아침 요약 · 후보 리그`, `🚨 후보 리그 파산 · …`).
   - **후보 리그만의 대화방을 따로 원하면** 대신 이렇게 합니다(데모 랩 봇은 자기 메시지를 읽고 있어서 같은 봇을 다른
     대화방에 쓰면 서로 메시지를 가져가므로, 후보 리그용 봇을 새로 만듭니다):
     1. 휴대폰 텔레그램에서 **@BotFather** → `/newbot` → 이름(예: 후보 리그 알림) → 아이디(끝이 `bot`) → 토큰이 나옵니다.
        **이 토큰은 채팅(개발자와의 대화 포함)에 절대 붙이지 마세요.** 서버에만 넣습니다.
     2. 서버에서:
        ```bash
        sudo bash /root/crypto-bot-research/deploy/candleague/setup_env.sh --own-telegram
        ```
        토큰을 붙여 넣으면(화면에 안 보임) 봇 이름을 보여 줍니다.
     3. 휴대폰에서 새 봇을 열고 **시작(START)**을 누릅니다. 친구분도 받으려면 친구분도 시작을 누르거나, 두 분이 있는
        그룹을 만들어 새 봇을 넣습니다. 서버 화면에서 엔터 → 찾은 대화방 이름이 나오면 `y`.
     4. 그 대화방마다 시험 메시지가 갑니다. 이어서 대시보드 설정(아래)도 같은 명령 안에서 진행됩니다.
     나중에 대화방을 바꾸고 싶으면 같은 명령을 다시 실행하면 됩니다.
   - 대시보드: 서버의 Tailscale 주소와 비밀값을 자동으로 넣고, 비밀번호는 두 번 입력합니다(화면에 안 보이는 게 정상,
     해시로만 저장). 비밀번호를 나중에 바꾸려면 `--new-password`를 붙여 다시 실행합니다.
   - 방화벽: 8091번은 **Tailscale에서만** 열립니다(인터넷에는 열지 않음). 규칙봇 8080을 Tailscale로 이미 열어 두었으면
     바뀌는 것이 없습니다.
3. **대시보드 열기**: Tailscale을 켠 PC·휴대폰에서 `http://(화면에 나온 주소):8091` → 비밀번호.
   - **비밀번호 없이 쓰고 싶으면**: `sudo bash /root/crypto-bot-research/deploy/candleague/setup_env.sh --no-password`.
     대시보드가 Tailscale 주소에만 열려 있을 때만 됩니다(두 분의 Tailscale에 로그인한 기기만 들어올 수 있고, 보기 전용이라
     주문 · 키가 없음). 다시 켜려면 `--new-password`.

### 멈춤 알림

- `candleague-watch`가 10분마다 따로 확인합니다. 엔진이 꺼졌거나, 처리 시각이 **1시간 넘게** 그대로면 텔레그램으로
  `⚠ 엔진 멈춤 확인 · 후보 리그`를 보냅니다(계속되면 3시간에 한 번만). 다시 돌면 `✅ 다시 정상 · 후보 리그`가 옵니다.

  `sudo journalctl -u candleague-live -n 40 --no-pager`
