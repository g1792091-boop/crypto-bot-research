# 후보 리그 (두 분용 설명)

5년 백테스트(research/fullgrid)에서 고른 커스텀값을 **실제 돈 없이** 지금 시장에서 따로 돌려 보는 종이 매매 봇입니다.
규칙봇·데모 랩과 섞이지 않게 **봇, 대시보드, 텔레그램 표시를 모두 따로** 둡니다. 2026-10-10 두 분 결정.

## 지금 도는 것: 관찰 목록 38개 (2026-10-11 두 분 결정)

백테스트를 통과한 커스텀값이 0개라서, **관찰 후보 16개 매매법의 커스텀값 38개**를 돌립니다(`ANALYSIS_KO.md` 8장,
`research/fullgrid/diag/watch_sel.json`). 통과한 값이 아니라 **앞으로의 성적으로 확인하려는 값**입니다.

커스텀값 하나마다 계좌 5개를 같은 신호, 같은 엔진으로 나란히 돌립니다.

| 계좌 | 숫자 | 익절·손절 | 크기 | 무엇을 보나 |
|---|---|---|---|---|
| 후보 | 커스텀값 | 커스텀값의 것 | 규칙봇과 같음 | 커스텀값이 버는가 |
| 1/4 크기 | 커스텀값 | 커스텀값의 것 | 증거금 1/4 | 크기를 줄이면 계좌가 덜 흔들리는가 |
| 청산만 바꾼 기본값 | 지금 숫자 | 커스텀값의 것 | 규칙봇과 같음 | 좋아진 게 숫자 덕인가, 청산 덕인가 |
| 기본값 | 지금 숫자 | 지금 규칙봇 것 | 규칙봇과 같음 | 규칙봇과 같은 조건 비교 |
| 동전 던지기 | 후보와 같은 시각, 방향은 동전 | 커스텀값의 것 | 규칙봇과 같음 | 방향을 맞힌 건가, 운인가 |

언제 무엇을 보는지는 시작 전에 고정했습니다(`research/fullgrid/WATCH_PREREG.md`).

- **늘**: 커스텀값마다 백테스트 예상 범위(하위 5%)보다 나쁘면 텔레그램 알림. 판정은 아닙니다.
- **11월 11일(1차)**: 규칙봇 쪽, 딥시크 쪽 묶음별로 후보 평균이 기본값과 동전 둘 다보다 나쁘면 그 묶음을 멈춥니다.
- **12월 11일(2차, 안 되면 1월 11일 한 번 더)**: 묶음의 후보 평균이 0보다 확실히 크고(운 검사), 기본값·동전보다 낫고,
  거래가 300번 이상이면 통과입니다. 통과한 묶음의 통과한 매매법만, 1/4 크기 이하·잃어도 되는 금액으로 실거래를 **두 분이**
  검토할 수 있습니다.

## 무엇을 하나요

- 백테스트를 통과한 후보마다 **계좌 하나**: 그 후보의 커스텀값 + 그 후보에 맞는 익절·손절(84가지 중 하나).
- 비교용으로 같이 도는 계좌:
  - **기본값 계좌**: 같은 매매법·같은 봉, 지금 숫자 + 지금 익절·손절(계단 잠금 10%, 2 ATR 손절). "커스텀값이 정말
    더 나은가"를 같은 기간에 바로 비교합니다.
  - **동전 던지기 계좌**: 후보와 같은 시각에 들어가되 롱/숏만 동전으로 정합니다. "방향을 맞힌 건가, 운인가"를 봅니다.
- 계산 규칙은 규칙봇과 똑같습니다: 규칙봇 엔진(PaperEngine), $5,000 시작, 좋은 자리 50/40배·보통 30/20배(증거금 =
  레버리지 %), 수수료·미끄러짐·펀딩, 마크 가격 청산, 파산 포함. 백테스트 계산기와 거래 하나하나 같은 결과가 나오는 것을
  시험으로 확인했습니다(84가지 익절·손절 모두).
- **처음 켜면 10월 1일부터 다시 돌려서** 그날까지의 성적을 바로 채운 뒤, 그다음부터는 5분마다 이어 갑니다.
  10월은 백테스트 자료(9월 30일까지)에 없던 날들이라 진짜 시험입니다.
- 바이낸스 **공개 자료만** 씁니다. 거래소 키가 없고 주문을 내지 않습니다.

## 어디서 보나요

- **대시보드**: 따로 주소(규칙봇 8080, 데모 랩 8090과 다른 **8091**). 규칙봇 v4와 같은 모양.
  - 순위표: 후보별 수익률, 거래 수, 승률, 최대 낙폭, 기본값과의 차이, 동전 던지기와의 차이
  - 후보 상세: 커스텀값과 익절·손절, 백테스트(시험 기간) 성적과 지금 성적 나란히, 거래 목록, 잔고 그래프
  - **터미널**(거래소 화면처럼 한눈에): 왼쪽 코인 6개(가격·24시간 변화·열린 포지션 수), 가운데 캔들 차트(15m · 30m · 1h · 4h,
    한국 시각)에 고른 계좌의 롱▲ · 숏▼ 진입과 청산●(이유 · 수익률), 열린 포지션의 진입가 · 손절 · 익절 선, 위쪽 줄에 가격 ·
    고가/저가 · 거래대금 · 마크 · 펀딩(다음 펀딩까지 남은 시간) · 봉 마감까지 남은 시간. 오른쪽은 고른 계좌 성적(기본값 · 동전과
    나란히)과 이 코인의 열린 포지션, 아래는 후보 리그 전체의 최근 체결. 체결이나 거래 줄을 누르면 그 코인 · 그 계좌로 바뀌고
    차트가 그 거래로 이동합니다. 시세는 대시보드 서버가 바이낸스 공개 자료를 받아 잠깐 저장해 두고 보여 줍니다(키 없음,
    브라우저는 바이낸스에 직접 접속하지 않음). 끄려면 env에 `CANDLEAGUE_DASH_LIVE=off`.
  - 요약 카드(후보 수, 기준 통과 · 미달 · 아직, 열린 포지션, 오늘 끝난 거래, 며칠째, 자료 지연), 거래 기록(계좌별로 걸러 보기)
  - 지금 포지션, 상태(마지막 처리 시각, 지연)
- **텔레그램**: 모든 메시지 앞에 `[후보 리그]`. 아침 요약 1번(09:00 KST)과 파산 같은 큰 일만 보냅니다(시끄럽지 않게).

## 언제 "좋다"고 하나요 (미리 정해 두는 기준)

- 거래가 **30번 넘게** 쌓이기 전에는 "아직 판단 이름"으로만 표시합니다(몇 번은 운으로 얼마든지 좋을 수 있음).
- 30번 이후: 평균 수익이 0보다 크고, **같은 기간 기본값보다 낫고, 동전 던지기보다 나은지**를 보여 줍니다.
- 실전에 쓸지는 그 성적을 보고 **두 분이 결정**합니다(베팅 크기 연구 결과와 함께).

## 설치와 서버

- 규칙봇 서버에 **손님으로** 설치합니다. 따로 사용자(`candleague`), 따로 폴더(`/opt/candleague`, `/var/lib/candleague`)를
  쓰고, CPU는 한 개의 30%, 메모리는 1.3 GB(대시보드 0.3 GB)까지만 쓰도록 묶여 있습니다. 규칙봇·데모 랩 파일은 읽지도 못하게
  막아 두었습니다(텔레그램 설정을 옮길 때 데모 랩 설정 파일을 한 번 읽는 것만 예외).
- 설치 스크립트가 먼저 남은 메모리를 봅니다. 2 GB보다 적으면 규칙봇 30일 판정에 영향이 없도록 **멈추고** 알려 줍니다.
- 기록(`league.db`)이 사라져도 걱정 없습니다. 10월 1일부터 다시 계산하면 똑같이 복구됩니다(같은 공개 시세, 같은 규칙).

### 설치 순서 (후보 목록이 올라간 뒤, 규칙봇 서버에서 10~15분)

1. **설치** (규칙봇 서버에 접속해서 한 줄):
   ```bash
   cd /root/crypto-bot-research && git pull && sudo bash deploy/candleague/install_candleague.sh
   ```
   끝에 `엔진: 켜짐`, `감시: 10분마다`가 보이면 됩니다. 처음에는 10월 1일부터 따라잡느라 몇 분~수십 분 걸립니다.
2. **텔레그램과 대시보드 설정** (한 줄, 비밀번호만 두 번 입력):
   ```bash
   sudo bash /root/crypto-bot-research/deploy/candleague/setup_env.sh
   ```
   - 텔레그램: 데모 랩 봇의 토큰과 받는 사람을 **서버 안에서** 옮겨 넣습니다. 새 키를 만들거나 채팅에 붙일 일이 없고,
     값은 화면에도 나오지 않습니다. 후보 리그 메시지는 같은 대화방에 **[후보 리그]**로 시작해서 옵니다.
   - 대시보드: 서버의 Tailscale 주소와 비밀값을 자동으로 넣고, 비밀번호는 두 번 입력합니다(화면에 안 보이는 게 정상,
     해시로만 저장). 비밀번호를 나중에 바꾸려면 `--new-password`를 붙여 다시 실행합니다.
   - 방화벽: 8091번은 **Tailscale에서만** 열립니다(인터넷에는 열지 않음). 규칙봇 8080을 Tailscale로 이미 열어 두었으면
     바뀌는 것이 없습니다.
3. **대시보드 열기**: Tailscale을 켠 PC·휴대폰에서 `http://(화면에 나온 주소):8091` → 비밀번호.

### 멈춤 알림

- `candleague-watch`가 10분마다 따로 확인합니다. 엔진이 꺼졌거나, 처리 시각이 **1시간 넘게** 그대로면 텔레그램으로
  `[후보 리그] ⚠️ 멈춤 확인 필요`를 보냅니다(계속되면 3시간에 한 번만). 다시 돌면 `✅ 다시 정상`이 옵니다.
- 엔진은 멈추면 30초 뒤 저절로 다시 켜집니다. 알림이 오면 화면을 개발자에게 보내 주세요:
  `sudo journalctl -u candleague-live -n 40 --no-pager`

### 상태 보기와 끄기

```bash
systemctl is-active candleague-live candleague-dash candleague-watch.timer     # 셋 다 active면 정상
sudo systemctl stop candleague-live candleague-dash candleague-watch.timer     # 잠시 끄기 (규칙봇과 무관)
```

## 순서

1. 오늘 밤: 백테스트가 도는 동안 후보 리그를 만듭니다.
2. 백테스트 결과 → 통과한 후보를 후보 리그에 넣습니다. 통과가 0개면 그대로 보고드리고, 무엇을 넣을지(넣지 않을지) 두 분과
   정합니다.
3. 두 분이 설치 → 첫날부터 10월 성적이 보입니다.
4. 1~2주 지켜본 뒤, 실전에 쓸지 두 분이 결정합니다.
