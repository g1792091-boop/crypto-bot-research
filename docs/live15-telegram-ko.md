# 규칙봇 15 텔레그램 메시지 미리 보기 (10/20부터)

10/20부터 실거래가 따라가는 페이퍼 봇은 **규칙봇 15**입니다. 이 문서는 두 분이 텔레그램으로 받게 되는 메시지를 종류마다 하나씩 보여 줍니다. 모든 예시는 실제 메시지를 만드는 코드를 그대로 돌려서 만든 것입니다(손으로 만든 가짜 계좌·가짜 시각이라 숫자는 예시입니다). 지금 서버 설정(`deploy/combo.live15.json`, `deploy/executor.live-bybit.json`, `deploy/executor.live-mexc.json`)을 기준으로 합니다.

- 🚨로 시작하는 메시지만 소리가 납니다(`TELEGRAM_SOUND=critical`). 나머지는 무음입니다.
- 같은 미리 보기는 서버에서 언제든 다시 볼 수 있습니다: `python -m paperbot.livecheck preview` (아무것도 보내지 않음). 예전 A+C 봇의 메시지는 `--old`.

## 1. 실시간 감시(1분마다)와 아침 점검

실거래 텔레그램의 대부분입니다. 진입·잠금·청산·손실 카드·알람이 여기서 나옵니다.

### 실행기 켜짐 · 무음

언제: 실행기가 켜질 때마다(업데이트·재시작 뒤). 신호등이 없으니 잔고만 나옵니다.

```
▶️ 바이비트 실행기 켜짐 · 잔고 $107.87
```

### 진입 · 무음

언제: 페이퍼 봇이 진입하면, 두 실행기가 따라 들어간 뒤(늦어도 3분 안에) 한 번. 실행기가 못 따라가면 그 줄에 ⚠가 붙고 알람이 따로 옵니다.

```
🟢 진입 · BTC 롱 · 40배
V39_ALL 1시간
페이퍼   67,250 · 손절 66,504 (-1.11%)
바이비트 ✅ 67,263 · 증거금 $32.29 · 손절 66,517 · 포지션 1/1
MEXC     ✅ 67,270 · 증거금 $32.29 · 손절 66,523 · 포지션 1/1
```

### 잠금 시작 · 무음

언제: 순ROE 11%에 닿아 +10%가 처음 잠길 때 한 번. 그 뒤 12%·17%·22%… 잠금은 따로 오지 않고 청산 메시지에 마지막 잠금이 나옵니다.

```
🔒 잠금 시작 · BTC 롱 · +10% 확보
바이비트 손절 66,517 → 67,507 · MEXC 손절 66,523 → 67,514
```

### 청산(이김) · 무음

언제: 이긴 청산마다. 실행기별 손익·잔고와 오늘 승패가 나옵니다(신호등 점은 없음).

```
✅ 청산 · BTC 롱 · 순ROE +17.1%
V39_ALL 1시간 · 2.1시간 보유 · 잠금 +17% 청산 (최고 +20%)
바이비트 +$5.33 (+16.5%) · 잔고 $113.20
MEXC     +$5.17 (+16.0%) · 잔고 $113.04
오늘 1승 0패 · 최근 20번 18승(90%)
```

### 손실 카드 · 무음

언제: 진 청산마다(같은 매매법의 반대 신호로 바로 나간 '빠른 청산(반대 신호)'도 포함). 첫 손실은 무음.

```
❌ 청산 · SOL 롱 · 순ROE -8.1%
S3_CMO_SANDWICH 30분 · 목록 2번 · 1.5시간 보유
진입 21:06 → 빠른 청산(반대 신호) 22:36 · 손절 거리 1.53% · 먼저 +6.0%까지
21시 · 이 설정의 5년 기준표가 없어요(지난 봇 기준표라 쓰지 않아요)
연속 손실 1번째
바이비트 -$2.95 (-8.7%) · 진입 +2.2 / 청산 -0.2bps
MEXC     -$3.12 (-9.2%) · 진입 +2.7 / 청산 +0.9bps
판정: 정상 범위 손실
```

### 손실 카드(소리) · 소리

언제: 연속 2번째 손실부터, 또는 실거래가 페이퍼와 크게 다를 때. 이제 '3연패면 멈춘다'가 아니라 '스스로 멈추지 않으니 두 분이 정하세요'라고 씁니다.

```
🚨 ❌ 청산 · ETH 롱 · 순ROE -50.0%
F3_BOS 30분 · 목록 12번 · 1.5시간 보유
진입 00:06 → 손절 01:36 · 손절 거리 1.53% · 먼저 +6.0%까지
00시 · 이 설정의 5년 기준표가 없어요(지난 봇 기준표라 쓰지 않아요)
연속 손실 2번째
바이비트 -$16.74 (-50.6%) · 진입 +2.0 / 청산 +0.0bps
MEXC     -$16.85 (-51.1%) · 진입 +3.0 / 청산 +0.7bps
판정: 연속 손실 2번째
지금 할 일: 연패해도 실행기는 스스로 멈추지 않습니다. 계속할지 두 분이 정하세요(두 실행기 모두 바로 닫고 멈추려면 sudo touch /var/lib/paperbot/STOP)
```

### 실행기 꺼짐(사람이 끔) · 무음

언제: systemctl stop이나 서버 재시작으로 실행기가 꺼질 때(무음).

```

열린 포지션은 거래소 손절이 지킵니다. 다시 켜기: sudo systemctl start paperbot-executor-mexc
```

### 진입 쉼 시작 · 무음

언제: 주말(토 00:00)과 미국 경제 발표 앞뒤 30분이 시작될 때. 나스닥 개장 뒤 30분은 평일 매일이라 메시지 없이 아침 점검에만 나옵니다.

```
⏸ 진입 쉼 시작 · CPI 발표 21:30 앞뒤 30분
22:00까지 새 진입 없음 (열린 포지션은 손절·잠금 그대로 관리돼요)
```

### 진입 쉼 끝 · 무음

언제: 그 쉬는 시간이 끝날 때. 24시간 안의 다음 쉼이 있으면 함께 씁니다.

```
🔔 진입 쉼 끝 · 다시 진입할 수 있어요
```

### 알람: 잔고 25% 하락 · 소리

언제: 실거래 잔고가 최고점보다 25% 이상 줄었을 때 한 번(20% 안으로 돌아오면 다시 켜짐). 이제 '50%면 멈춘다'가 아니라 멈추지 않는다고 쓰고, 멈추는 두 방법을 적습니다.

```
🚨 바이비트 실거래 잔고가 최고점보다 26% 줄었습니다
잔고 $79.50 · 최고 $107.87
잔고가 줄어도 실행기는 스스로 멈추지 않습니다(낙폭 멈춤 없음)
지금 할 일: 두 분이 계속할지 정하세요(멈추려면 sudo systemctl stop paperbot-executor, 포지션은 거래소 손절이 지킴 · 두 실행기 모두 바로 닫고 멈추려면 sudo touch /var/lib/paperbot/STOP)
```

```
🚨 바이비트 실거래가 페이퍼가 이긴 거래에서 2번 졌습니다(최근 20번 중)

- 10/20 18:10 BTC 롱 S3_CMO_SANDWICH: 페이퍼 +$36.00, 실거래 -$1.10

지금 할 일: 아침 점검의 실제 비용 줄과 손실 카드를 보고, 거래소 앱의 체결 내역과 비교하세요
```

### 알람: 멈춤 요약 · 소리

언제: 실행기가 스스로 멈췄을 때(이제는 반대 방향 포지션 같은 안전장치 때문일 때만). 이유·직전 거래·잔고·푸는 순서를 씁니다.

```
🚨 바이비트 실행기가 멈췄습니다 · 이유: 방향이 반대인 포지션(실행기 안전장치)
멈춤 기록: 방향이 반대인 포지션 발견
멈추기 전 거래:
- 10/20 21:30 SOL 롱 S3_CMO_SANDWICH +10.8% (+$3.58)
- 10/20 22:30 SOL 롱 S3_CMO_SANDWICH +10.8% (+$3.58)
잔고 $111.20 (시작 $100.00, +11.2%)
페이퍼 거래 19번(표본 작음)
안내:
- 이 멈춤은 연패·낙폭 때문이 아닙니다(비상 정지 파일이나 실행기 안전장치). 두 분이 같이 원인을 본 뒤에 풉니다
- 다시 켤지는 두 분이 정합니다: STOP 파일 지우기 → 실행기 끄기 → `clear-halt`
지금 할 일: 두 분이 같이 원인을 본 뒤 이 순서로 풉니다(live-safety.md 3-5)
sudo rm /var/lib/paperbot/STOP   (비상 정지 파일이 있었다면)
sudo systemctl stop paperbot-executor
cd /opt/crypto-bot-research && sudo -u paperbot-exec /opt/paperbot/venv/bin/python -m paperbot.executor clear-halt --config /etc/paperbot/executor.json --by 이름 --note "이유"
sudo systemctl start paperbot-executor
```

### 아침 점검 · 무음

언제: 매일 09:10. 어제 09:00~오늘 09:00의 대조·실제 비용·손실 카드·성적표, 오늘 진입 쉬는 시간(경제 발표·나스닥 개장). 이상 없으면 무음.

```
📋 실거래 일일 점검 · 이상 없음
10/28(수) 09:00 ~ 10/29(목) 09:00

- 오늘 진입 쉬는 시간: 21:00~22:00 PCE 물가 · 22:30~23:00 나스닥 개장

대조(다시 계산): 거래 2/2 같음 · 신호 2/2 같음

실제 비용(어제 닫힌 실거래, 페이퍼 가격 대비 +가 불리)
- 바이비트 1번 +$7.10: 진입 +1.8bps · 청산 -1.1bps · 수수료 0.055%(가정 0.055%) · 펀딩 +$0.00
- MEXC: 어제 닫힌 거래 없음

손실 카드 1장
```

## 2. 실행기(바이비트·MEXC)가 직접 보내는 메시지

실행기는 평소 거래(진입·잠금·청산)에는 메시지를 보내지 않습니다. 그건 위 1장의 🟢·🔒·✅·❌가 맡습니다. 실행기는 **문제가 있을 때만** 머리말 `[바이비트 실거래 실행기]` / `[MEXC 실거래 실행기]`를 붙여 보냅니다. 연패나 낙폭으로 멈추는 일은 없어서, 예를 들어 손절이 4번 연속 나와도 실행기는 아무 메시지 없이 계속 따라갑니다(가짜 거래소 시험: 연속 손실 4번 뒤 멈춤 없음, 메시지 0개).

### 늦은 진입을 따라가지 않음 · 무음(경고)

언제: 페이퍼 진입이 3분(180초) 넘게 지난 뒤에야 보였을 때. 그 거래는 따라가지 않습니다.

```
[바이비트 실거래 실행기] paper 진입이 603초 전이라 따라 하지 않습니다
```

### 비상 정지 파일(STOP) · 소리

언제: 누군가 `sudo touch /var/lib/paperbot/STOP`을 했을 때. 열린 포지션을 시장가로 닫고 멈춥니다. 이제 실행기가 멈추는 길은 이것과 실행기 안전장치(반대 방향 포지션, 손절을 걸 수 없음 등)뿐입니다.

```
[바이비트 실거래 실행기] 거래를 멈춥니다(사람이 풀 때까지): 비상 정지 파일이 있습니다(/var/lib/paperbot/STOP)
```

그 밖의 경고(진입 주문 거절, 손절을 다시 검, 모르는 포지션을 닫음, 요청 한도 등)도 같은 머리말로 옵니다.

### 설정 확인(check-config) 화면 · 텔레그램 아님

서버에서 설정을 바꾼 뒤 확인하는 화면입니다. 끝 세 줄:

```
멈춤: 연패·낙폭으로는 멈추지 않음 (비상 정지 파일 /var/lib/paperbot/STOP만)
신호등: 꺼짐 (paper의 모든 진입을 따라감)
준비됨
```

## 4. 실거래 분석 팀(AI)

언제: 실행기가 2번 연속 졌을 때(손실 회의), 페이퍼 거래 40·80·120…번(판단 회의), 월요일 10시(주간 보고). 타이머를 켰을 때만. 결론만 무음으로 옵니다.

```
🧭 [실거래 분석팀] 주간 보고 🟡 지켜보기
페이퍼 22번 중 19번 이김(86%), 본전 승률 83% 위지만 아직 표본이 작아요
· 바이비트·MEXC 모두 페이퍼를 그대로 따라감
· 손실 3번 중 2번이 -50% 손절
· 추격 막기로 거른 신호 4개
시험해 볼 아이디어 1개 (결정은 두 분)
자세히: 대시보드 › 실거래 › 분석팀 · AI 의견이라 참고만, 매매는 고정 규칙대로
```

AI에게 주는 "고정 규칙"은 이제 지금 돌고 있는 설정 파일에서 읽습니다(예전에는 "증거금 40% · 그 뒤 3%씩 · 3연패 멈춤 · 50% 빠지면 멈춤"이 박혀 있었음):

```
- 매매법 15개
- BTC 40배 · 나머지 30배
- 증거금 잔고의 30%
- 한 번에 포지션 하나
- 시장가 진입
- 손절 순ROE -50%(수수료·슬리피지 포함: 40배 가격 1.11%, 30배 가격 1.53%)
- 계단 익절(순ROE 11%에서 10% 잠금, 15%에서 12%, 20%에서 17%, 그 뒤 5%마다 (닿은 순ROE - 3%))
- 빠른 청산: 같은 매매법이 반대 신호를 내면 바로 청산(첫 잠금 전까지만)
- 추격 진입 막기 4개 매매법(롱은 7일 범위 위 20%·24시간 고점 쪽 10% 안이면, 숏은 아래쪽이면 진입 안 함)
- 코인 6개(BTC ETH SOL DOGE LTC BCH)
- 한국 시간 주말 진입 없음
- 미국 경제 발표 앞뒤 30분 진입 없음
- 나스닥 개장 뒤 30분 진입 없음
- 거래소에 거는 손절
- 연패·낙폭으로 저절로 멈추지 않음(비상 정지 파일 /var/lib/paperbot/STOP으로만 멈춤)
- 손절 한 번 최대 잔고의 35%
- 신호등 없음(실거래는 페이퍼의 모든 진입을 따라감)
- 실거래 금액 바이비트 $100 · MEXC $100
```

판단 기준으로는 "이 봇에는 40번 판단 기준(88%/82%)이 없음(그 숫자는 지난 봇의 5년 기준표로 정한 것). 두 분이 페이퍼 승률을 본전 승률(bot.break_even)과 시작 근거(bot.start_basis)에 비교해 판단"이라는 문장을 주고, 본전 승률 83.3%(단순 합계)와 시작 근거(지난 2주 다시 판정 58승 4패, 같은 장 동전 던지기 75%)를 함께 줍니다. 5년 숫자(맞춘 91% · 현실 75%)는 지난 봇 것이라 주지 않습니다.

## 5. 더 이상 오지 않는 알림

| 알림 | 왜 안 오나 |
|---|---|
| 🚦 신호등 바뀜 | 신호등을 껐습니다(`signal_light_n` 0, 10/19 결정). 두 실행기가 페이퍼의 모든 진입을 따라갑니다. 진입 메시지의 "⛔ 신호등이 막음", 청산 메시지의 신호등 점(🟢🔴⚪), 실행기 켜짐·따라가지 않음·멈춤 요약·아침 점검의 신호등 줄도 같이 없어졌습니다. 꺼져 있다는 말은 check-config에서 한 번만 나옵니다. |
| 3연패 멈춤 | 연패 멈춤을 없앴습니다(10/19). 손실 카드의 "3연패면 실행기가 스스로 멈춥니다"도 "연패해도 스스로 멈추지 않습니다. 계속할지 두 분이 정하세요"로 바뀌었습니다. |
| 낙폭 50% 멈춤 | 낙폭 멈춤도 없앴습니다(10/19). "잔고 25% 하락" 알람은 남아 있고, "50%가 되면 멈춥니다" 대신 "스스로 멈추지 않습니다"와 멈추는 방법을 씁니다. |
| 🏁 40번 도달 / 아침 점검의 "판단: 40번에서 88%…" 줄 | 88%·82% 기준은 지난 봇(A+C 합본)의 5년 기준표로 정한 숫자입니다. 같은 페이퍼 계좌의 첫 40번도 지난 봇 거래라 맞지 않습니다. 규칙봇 15는 첫 1~2주 승률을 시작 근거와 본전 승률(약 83~86%)에 비교해 두 분이 판단합니다. |
| 📊 월요일 주간 성적표 | 매매법별 성적을 지난 봇의 5년 기준표와 비교하는 표라, 기준표가 없는 규칙봇 15에는 만들지도 보내지도 않습니다. |
| 🚨 기대 범위 밑 · 📉 참고(백테스트 하위 5%) | 5년 기준표가 없어서 비교할 범위가 없습니다. 손실 카드의 백테스트 숫자(백테스트 승률·이 장세·이 코인·백테스트 최장 연패)도 빠지고 "이 설정의 5년 기준표가 없어요" 한 줄만 나옵니다. |
| ⏳ 진입 대기 | 신호 뒤 돌파를 기다리던 연구 세팅은 지난 봇에만 있었습니다. 규칙봇 15는 신호가 나면 바로 진입합니다. |
