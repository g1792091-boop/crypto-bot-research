## 2. 매매 규칙 (모든 계좌 공통)
| 항목 | 내용 |
|---|---|
| 신호 | 백테스트방 잠긴 코드(해시 확인), 확정된 봉에서만 |
| 진입 | 봉이 끝나 신호가 계산되면 그 순간 가격에 시장가 진입 + 슬리피지 0.02%. 계산에 걸린 시간과 그 사이 가격 변화를 기록 |
| 포지션 | 계좌마다 1개. 같은 봉에서 여러 코인에 신호가 나면 BTC → ETH → SOL → DOGE → LTC → BCH 순서. 크기 조건에 막히면 다음 코인 |
| 손절 | 진입가 − 방향 × **2 × ATR14**(신호 봉) |
| 레버리지·증거금 | 높은 쪽부터 40%×50배 → 40%×40배 → 30%×30배 → 20%×20배. 조건: 거래소 레버리지 구간 허용, 손절이 청산가보다 max(1 ATR, 0.2%) 안쪽, 손절 손실 ≤ 자금의 15%. 모두 안 되면 진입 안 함(기록) |
| 익절 | 계단식 잠금. 순 ROE 최고 +12% → +10% 잠금, +17% → +15%, +22% → +20%, 이후 5%마다. 잠금은 올라가기만 함 |
| 청산 판정 | 1분봉과 마크 가격으로 판정. 한 봉에서 잠금이 올라가면 다음 봉부터 적용 |
| 없는 것 | 고정 익절, 시간 청산, 반대 신호 청산, 낙폭 정지 |
| 알림 | 낙폭 −20 / −30 / −40% 알림만 |
| 파산 | 자금 $10 미만이면 그 계좌 정지("파산") |
| 비용 | 수수료는 계정 실제 수수료율(없으면 0.05%), 슬리피지 0.02%, 펀딩은 **실제 펀딩비와 실제 시각** |
| 레버리지 구간 | 거래소 실제 값(`/fapi/v1/leverageBracket`, 읽기 전용 키) |

## 3. 그림자 기록 (계좌 없이 기록만)
- **지정가 진입:** 신호 가격에서 0.25 ATR 유리한 곳에 지정가를 걸었다면 체결됐는지, 체결됐다면 같은 청산 규칙으로 결과가 어땠는지
- **봉 중간 진입:** 신호 조건이 봉 안에서 처음 켜진 시각, 봉이 끝날 때까지 유지됐는지(5분 단위)
- **순서 때문에 놓친 신호:** 다른 코인을 잡았다면 결과가 어땠는지

## 4. 점검과 합격 기준
**1차 점검: 시작 후 30일**

| 판정 | 조건 |
|---|---|
| 판단 보류 | 거래 30건 미만 |
| **1차 합격** | 거래 30건 이상 **그리고** 자금 > 시작 금액($5,000) **그리고** 같은 봉 동전 봇 3개보다 모두 높음 **그리고** 파산 아님 |
| 불합격 | 그 밖 |

**2차 확인: 1차 합격 계좌만, 그다음 30일.** 그 30일 동안 새로 난 거래만으로 다시 봅니다.
- 거래 30건 이상
- 그 기간 순손익 플러스
- 그 기간 동전 봇 3개보다 모두 나음

**2차까지 통과해야 "실거래 검토 대상"입니다.** 실거래 여부는 두 분이 정하고, 시작은 소액·매매법 1개부터입니다.

**우연 기준:** 과거 비교에서는 216개 계좌 중 약 5%(10~11개)가 한 기간에 시작 금액을 넘었고, 두 기간 모두 넘은 것은 1개였습니다. 그래서 1차 합격이 9개 안팎 나오는 것은 **우연으로도 설명됩니다.** 2차 확인을 두는 이유입니다.

**백테스트 예상과 비교:** 과거 비교에서 파산까지 걸린 날의 중앙값은 5분봉 18일, 15분봉 75일, 30분봉 154일, 1시간봉 340일이었습니다. paper가 이와 크게 다르면 운영 감사관과 데이터 품질 감시관이 원인을 먼저 봅니다(엔진 오류 가능성).

## 5. 에이전트 팀 원칙
- 원본 195개 계좌는 에이전트가 바꿀 수 없습니다.
- 에이전트의 개선안은 거래 30건 이상인 매매법에 대해서만 받습니다. 자율 승인관이 승인하면 **새 계좌(예: "V4.5-15m-개선1")**를 원본과 같은 시작 금액($5,000)으로 따로 시작하고, 원본은 그대로 둡니다.
- 아침 계획의 허용 방향은 원본 계좌에 적용하지 않고 "적용했다면"만 기록합니다.
- 실제 주문 기능은 없습니다. 바이낸스 키는 읽기 전용입니다.
