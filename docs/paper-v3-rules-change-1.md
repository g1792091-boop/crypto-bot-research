# paper v3 — 규칙 변경 1: 5분봉 제외와 처음부터 다시 시작

작성: 2026-10-04 (KST). 두 분 결정("5분봉은 다 빼자", 2026-10-04 대화). 이 문서는 `docs/paper-v3-rules.md`와 `docs/paper-v3-rules-addendum.md`에 덧붙는 기록입니다. 두 문서는 해시로 고정돼 있어 고치지 않고, 아래 내용이 그 두 문서의 해당 부분보다 앞섭니다.

## 1. 바뀐 것
| 항목 | 전 | 이제 |
|---|---|---|
| 봉 | 5분, 15분, 30분, 1시간, 4시간 | **15분, 30분, 1시간, 4시간** (5분봉 뺌) |
| 매매법 계좌 | 36 × 5 = 180개 | 36 × 4 = **144개** |
| 동전 던지기 봇 | 봉마다 3개 = 15개 | 봉마다 3개 = **12개** |
| 합계 | 195개 | **156개**, 계좌마다 $5,000 |
| 1차 판정(Q1) 묶음 | 5분~1시간 매매법 계좌 | 15분·30분·1시간 매매법 계좌 36 × 3 = **108개** (4시간봉은 그대로 관찰용) |
| 1분봉 읽는 시각 | 마감 직후 | 마감 **5초 뒤** (`paperbot/feed.py`, 확정 전 1분봉을 읽던 문제를 고침) |
| 실험 | 이전 실행에 이어서 셈 | **처음부터 다시 시작**. 새 계좌를 새로 만들고, 그 시각이 새 시작입니다 |
| 이전 실행 | — | 지우지 않고 보관 (`/var/lib/paperbot/archive/run-<시각>/`, `deploy/paperbot-reset.sh`) |

- 5분봉 매매법 계좌와 5분봉 동전 던지기 봇은 만들지 않습니다. 5분봉 신호도 계산하지 않습니다.
- 5분봉 자료 자체는 봇 안에서 15분·30분·1시간·4시간·일봉을 만드는 재료로 계속 씁니다(거래는 없음).

## 2. 왜
근거는 5년 자료입니다. 5분봉은 매매법 전체를 합쳐 거래당 평가 자금 **−2.3%**(−2.32%)였고, 36칸 중 **34칸이 통계적으로 유의한 손실**, 시험 계좌 72개 중 **64개가 파산**했습니다.

## 3. 바뀌지 않은 것
- 손절 2 × ATR14, 계단식 익절 잠금(+12% → +10%, 이후 5%마다).
- 레버리지 50 / 40 / 30 / 20배, 증거금 40% / 40% / 30% / 20%와 그 조건.
- 파산 기준 $10 미만, 시작 금액 $5,000, 충전 없음, 계좌당 포지션 1개, 코인 순서.
- 코인 6개(BTC, ETH, SOL, DOGE, LTC, BCH). XRP는 신호 기록만.
- 일봉은 계좌 없이 신호 기록만.
- 4시간봉은 처음부터 관찰용(Q3). 1차 판정에 넣지 않습니다.
- 합격 기준, 체크포인트 일정(시작 뒤 30, 60, 90 … 180일), 동전 봇 비교와 FDR 10%, 그 밖의 모든 규칙.

## 4. 이번이 마지막 재시작
이번이 마지막 재시작입니다. 새 시작부터 **30일 동안 규칙과 매매 코드는 그대로** 둡니다. 그 사이 바꿀 일이 생기면 원래 규칙대로 버전을 올리고(v4) 새 계좌로만 돌립니다.

## 5. 새 계좌 수
**156개** = 매매법 36개 × 봉 4개(144개) + 동전 던지기 봇 봉마다 3개 × 4(12개).
