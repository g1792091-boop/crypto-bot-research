# 사용법 — GH Coin 자기개선 루프 (Phil 방식)

Claude Code 가 GH Coin 데모 성적과 예측 채점을 읽고, 허용된 정책만 고쳐서 git 커밋으로 남깁니다. 주문은 하지 않습니다.

## 1. 준비 (한 번만)
- GHCoin.exe 를 켜 둡니다. 앱이 1분마다 `문서\GHNano 사무실\neutron\state.json` 을 씁니다. 이 파일이 있어야 채점할 수 있습니다.
- 이 폴더(`문서\GHNano 사무실\ghcoin-phil`)에서 PowerShell 을 엽니다.
  - 탐색기에서 이 폴더 주소창에 `powershell` 을 입력하고 Enter 를 누르면 됩니다.

## 2. 성적표 보기 (언제든)
```
node core/score.mjs
```
- 첫 줄 `settled=… win_rate=… pnl=$…`
  - 청산된 데모 거래 수, 이긴 비율, 손익입니다.
- 둘째 줄 `brier: agent=… market=… delta=…`
  - 앱이 말한 확률이 얼마나 잘 맞았는지(agent)와, 아무 정보 없이 찍은 기준선(market)을 비교합니다.
  - **delta 가 음수(−)면 기준선보다 잘 맞힌 것**입니다. 이게 진짜 실력 지표입니다.
  - 새 버전 앱을 켠 뒤 예측이 쌓이고 결과가 나와야 숫자가 생깁니다.
  - AI 시장 읽기는 1시간 뒤, 추천·데모 거래는 익절이나 손절이 난 뒤에 채점됩니다.

## 3. 루프 한 번 돌리기 (직접 실행)
```
.\loop.ps1 1
```
- Claude Code 가 순서대로 일합니다: 채점 → (새 결과가 있으면) 회고 → 근거가 있으면 정책 수정·앱에 적용 → git 커밋.
- 여러 번 돌리려면 `.\loop.ps1 5 60` 처럼 씁니다. 5번을 60분 간격으로 돌립니다.
- 스크립트 실행이 막혀 있으면 `powershell -ExecutionPolicy Bypass -File .\loop.ps1 1` 로 실행합니다.
