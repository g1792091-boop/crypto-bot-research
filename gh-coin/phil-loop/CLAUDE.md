# GH Coin 자기개선 루프 (Phil 방식)

GH Coin 데모 매매의 성적과 예측 채점을 읽고, 허용된 정책 손잡이만 스스로 고쳐 git 커밋으로 남기는 실험이다.
bennyjo/phil 의 구조를 따랐다: 매 사이클 정산 → 채점 → 회고 → 자기 전략 수정 → 커밋. 차이는 두 가지다.
- 예측 시장이 아니라 GH Coin 앱의 코인 선물 데모를 대상으로 한다.
- 실거래 경로가 아예 없다.

- `core/` — 보호된 엔진.
  - `score.mjs`: `../neutron/state.json` 을 읽어 성적·브라이어를 보고한다.
  - `apply.mjs`: 정책을 검사해 앱 받은 편지함으로 보낸다.
  - 루프는 이 폴더를 고칠 수 없다.
- `strategy/` — 루프가 고치는 것. 이 폴더의 git 이력이 실험의 결과물이다.
  - `policy.json`: 허용 손잡이
  - `playbook.md`: 판단 기준과 지식
- `journal/` — 회고(`retros/`), 사이클 기록(`cycles.log`), 사람에게 보내는 제안(`proposals.md`).
- `CYCLE.md` — 매 사이클 순서.

## 안전
- GH Coin 의 안전 규칙은 그대로다.
  - AI 는 주문하지 않는다.
  - 실거래는 기본 꺼짐이고 테스트넷부터 쓴다.
  - 최소 20배, 손절은 청산거리 40% 이하.
- 이 루프가 바꿀 수 있는 것은 "AI 자율 진입 문턱·횟수 · 리스크 줄이기 · 코인 제외 · 관망 규칙 제안"뿐이다. 앱이 범위를 다시 검사한다.
