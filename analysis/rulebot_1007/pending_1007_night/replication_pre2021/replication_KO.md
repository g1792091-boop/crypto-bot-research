## 2. 방법 (이전 데이터를 보기 전에 `PRESPEC.json`에 고정)

- **신호:** 저장소 코드를 읽기 전용으로 불러 씀.
  - 36개 전략: `research/entry_study/final_signals.py`의 `load_bars` + `signal_arrays`(잠긴 sweep_lib, 해시 확인, DOGE = `doge_join`)
  - DeepSeek 44개: `research/deepseek200/lib_c.entries`(BTC 맥락 포함, 양쪽 동시 신호는 롱 우선)
  - 저장소에는 아무것도 쓰지 않았습니다(`git status` 깨끗함).
- **청산·비용:** 검증된 5년 검사와 같습니다.
  - 다음 봉 시가 + 슬리피지 0.02%, 손절 2×ATR14, paper v3 ROE 래더(`profiles._scan`)
  - v4 "normal" 사이징(30x/30%, 20x/20%, $5,000). 사이즈가 안 나오는 신호는 뺌
  - 테이커 0.05%×2, 슬리피지 0.02%×2, 펀딩 0.01%/8h 고정
- **동일성 확인:** 같은 시뮬레이터를 5년 데이터에 돌려 검증된 피클과 비교했습니다.
  - 36개 4h 70,103행, DeepSeek 4h 122,793행이 **한 행도 빠짐없이 일치**했습니다. 레버리지 일치 100%, R·gross 최대 차이 0(`out/parity_5y_core4h.log`, `out/parity_5y_ds4h.log`).
  - 5년 F16 행은 agg_cells와 같은 값을 냈습니다(+0.0262, t 3.886).
- **지표:**
  - gross R = 청산가 기준 수익 / 손절 폭(비용 전, 청산 제외)
  - net R = 비용 후
  - t는 주(7일) 단위로 묶은 표준오차로 계산(v3agg와 같음)
- **방향성분(추가):** 2020-21년은 큰 강세장이라 래더 청산이 양쪽 방향 모두에서 이익을 냈습니다(4장). 그래서 같은 순간 **반대 방향으로 들어간 경우**도 함께 계산했습니다.
  - 방향성분 = (gross − 뒤집은 gross)/2. "동전 던지기 대비 방향을 맞힌 몫"입니다.
  - 5년 데이터에서도 같은 칸으로 계산했습니다(`out/y5_flip_cells.csv`).
- **판정 규칙(미리 정함):**
  - 재현 (BH): 부호 같음 + |t| ≥ 1.5 + 5년 방향 한쪽 p의 BH q ≤ 0.05(23칸 묶음)
  - 약한 재현: 부호 같음 + |t| ≥ 1.5, BH는 통과하지 못함
  - 반대로 나옴: 부호 반대 + |t| ≥ 1.5
  - 불확실: 나머지
- **함께 보는 숫자:**
  - **기대 t**: 진짜 효과가 5년 추정치와 같다면 이 표본에서 나올 t
  - **검정력**: P(t ≥ 1.5)
  - **차이 z**: 이전 기간과 5년이 통계적으로 다른가
