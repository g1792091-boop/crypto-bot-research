| 줄 | 계좌 하나 × 레버리지 하나. 데모 봇은 56계좌 × 20·30·40·50배 = 224줄 |

| ROE | 증거금 대비 손익. 30배에서 가격 1% = ROE 30% |
| 노출 | 포지션 크기 ÷ 잔고 = 배수 × 증거금 비율. 30배·40% = 잔고의 12배 |
| 동전 던지기 / 동전 쌍둥이 | 방향을 무작위로 정하고 나머지 규칙은 같은 비교 계좌. 이것보다 못하면 실력이라 할 수 없음 |

| 두 절반 | 기간을 앞·뒤 반으로 나눠 둘 다 좋은지 봄. 한쪽만 좋으면 운일 가능성이 큼 |

| p | "실력 없이 운으로 이만큼 나올 확률". 작을수록 운이 아닐 가능성. 0.05가 흔한 기준 |

## 10. 다시 만드는 방법

```
cd analysis/review1024/other
python3 run_all.py \
  --demo <demo_export_20261024_1427_1.zip> <demo_export_20261024_1427_2.zip> \
  --old-demo <demo_export_20261017_0017_1.zip> <demo_export_20261017_0017_2.zip> \
  --extra <extra_export_20261024.zip> \
  --work <새 빈 폴더> | tee run.log
```

- zip은 새 빈 폴더에 데이터 파일만 풀립니다. DB는 읽기 전용으로만 엽니다. 약 40초 걸립니다.
- 부트스트랩은 씨앗을 고정해서 다시 돌려도 같은 숫자가 나옵니다.
