## 1. 지표 (모두 닫힌 봉, 봉 종가 기준)

- RSI26: `fg.rsi(close, 26)`(와일더, `frcore._ind`와 같음). > 50 상승, < 50 하락.
- MOM10: close − close[10봉 전]. > 0 상승, < 0 하락.
- ROC9: `fg.roc(close, 9)`. 진입 R = 0선 상향 돌파(직전 봉 ≤ 0, 이번 봉 > 0), 숏은 하향 돌파.
- 클링거(K): TradingView 기본 지표 "Klinger Oscillator" 식. sv = (hlc3 − 직전 hlc3 ≥ 0 이면 +거래량, 아니면 −거래량),
  KVO = EMA34(sv) − EMA55(sv), 신호선 = EMA13(KVO). EMA는 Pine `ta.ema`(α = 2/(n+1), 첫 값 SMA 시드).
  진입 K = KVO가 신호선을 위로 넘음(직전 봉 KVO ≤ 신호선, 이번 봉 KVO > 신호선), 숏은 아래로.
  직접 구현하고 점검: (a) 같은 식의 순수 파이썬 반복문 구현과 값이 같은지(상대오차 1e-9), (b) 라이브러리 `pine_indicators.pine_ema`로
  만든 값과 같은지, (c) 다른 클링거 식 두 개(`third_party/.../fg_indicators.klinger_oscillator` 근사식, 원래 클링거 식
  `research/vwap30/code/vwfriend.klinger`)와 교차 시점이 얼마나 겹치는지(±1봉) 보고. 판정에는 (a)(b)만 씀.
