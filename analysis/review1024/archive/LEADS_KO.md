  2. **돌파 + 불타기를 노출 10~20배로 돌린 경우**(vwap30 7차). 30일 창의 0.4~2.4%가 ×5였지만, 21~53%는 −90%를 넘게 잃었습니다.

     그때 나머지 경우는 거의 모두 잔고 10% 이하로 떨어졌습니다.
- 비용을 빼고도 두 기간 모두 플러스로 확인된 것 중 가장 좋은 것(K01)도 증거금 10%에서 한 달 약 +5%입니다.
  목표와는 두 자릿수 차이가 납니다.

## 1. 읽는 법

- **상태**
  - 처음 보는 기간 확인 = 고른 뒤 한 번도 안 본 기간에서 같은 방향으로 나옴.
  - 엇갈림 = 기간마다 다르거나, 확인 기간도 예전에 본 기간이라 약함.
  - 시험 안 함 = 산수나 설계만 있음.
  - 고른 기간만 = 같은 자료로 찾고 같은 자료로 봄.
  - 처음 보는 기간 실패 = 확인에서 무너짐.
- **희망 점수 0~5**: 두 분 목표(한 달 ×6)에 얼마나 도움이 되는지입니다.
  - 무게는 처음 보는 기간 확인 > 엇갈림 > 시험 안 함 > 고른 기간만 순서입니다.
  - 비용을 뺀 뒤의 크기와, 지금 실행기(Bybit · WOO X Pro)에서 돌릴 수 있는지도 함께 봤습니다.
  - 5점은 없습니다.
- **원래 ID**: 노트마다 L 번호가 겹쳐서 앞에 글자를 붙였습니다.
  - H = read_hunt, G = read_grid, EX = read_exits, N = read_newinfo
  - R = read_regime, M = read_misc, D = read_docs5y, A = read_docsai
- **단위**
  - R = 손절 한 번의 크기입니다.
  - '거래당 %'는 따로 적지 않으면 $5,000 지갑 대비입니다.
  - '거래당 순ROE'는 증거금 대비이고 수수료를 뺀 값입니다.
  - 기간 이름(고르는 / 시험 / 추가)은 연구마다 다릅니다. 표에 날짜를 적었습니다.
- **비용**: 모든 옛 연구는 왕복 0.14%(테이커 0.05% × 2 + 미끄러짐 0.02% × 2)로 계산했습니다.
  WOO X Pro 0.042%에 90% 페이백을 넣으면 왕복 약 0.048%로, 약 0.35배입니다(K03).
