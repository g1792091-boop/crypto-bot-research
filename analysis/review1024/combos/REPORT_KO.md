## 8. 솔직한 한계

| `cb_build.py` | 두 압축 파일을 새 빈 폴더에 안전하게 풀고, 거래 표 · 계좌 표 · 신호 다시 계산 표를 만듦 |
| `cb_combos.py`, `cb_sig.py`, `cb_core.py`, `cb_lib.py` | 조합 시험 전부, 운 검사, 목표 경로 |
| `trades_all.csv` | 두 봇의 끝난 거래 17,495번 (거래당 ROE · 지갑 수익률 · 배수 등) |
| `accounts_all.csv` | 계좌 1,519개 |
| `signals_sim.csv.gz` | 규칙봇 신호 47,984개의 다시 계산(원래 방향과 반대 방향). 저장소 크기 때문에 gzip으로 압축해 둠. `cb_build.py`를 다시 돌리면 압축 안 된 `signals_sim.csv`가 새로 만들어짐 |
| `combos_all.csv` | 시험한 조합 762줄 전부 (고르기 · 확인 · 무작위 비교 · 롱/숏 · 시장 효과) |
| `combos_consistency.csv` | 같은 구성의 세 가지 나누기 결과 나란히 |
| `family_overview.csv` | 조합 종류별 가운데 · 플러스 비율 · 무작위보다 나은 비율 |
| `persistence.csv` | 앞 기간 실력이 뒤 기간에 이어지는지 |
| `goal_path.csv`, `goal_path_pooled.csv`, `goal_daily.json` | 목표 경로(나누기 하나씩 / 모두 합쳐서) |
| `default_vs_custom.csv` | 기본값 vs 커스텀값 49쌍 |
| `market.csv` | 기간별 코인 움직임과 같은 방향 동전 기준값 |
| `build_meta.json`, `combos_summary.json` | 기간, 파일 해시, 다시 계산 검증, 요약 숫자 |

다시 돌리기(이 폴더에서, 약 10분):

```bash
cd analysis/review1024/combos
python3 cb_build.py  <규칙봇 export zip> <커스텀값봇 export zip> <새 빈 작업 폴더>
python3 cb_combos.py <규칙봇 export zip> <커스텀값봇 export zip> <같은 작업 폴더>
```

- 압축 파일 안의 코드는 실행하지 않습니다. sqlite는 읽기 전용으로 엽니다. 무작위 뽑기는 씨앗(20261024)을 고정해서 같은 결과가 나옵니다.
- 배수 규칙과 진입 품질 판정은 저장소의 `paperbot/sizing.py` · `paperbot/levrule.py`를 그대로 불러 씁니다.
