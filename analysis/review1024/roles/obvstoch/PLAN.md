## 1. 무엇을 시험하나

친구 원칙: 추세형 지표는 진입하지 않고 **상위 봉에서 방향만** 본다. 진입은 그 방향일 때만 **타이밍 지표(스톡 RSI)** 가 과매도에서
올라올 때(롱) / 과매수에서 내려올 때(숏). 이것을 그대로 만들고, 이웃(다른 추세 × 다른 타이밍)도 같은 방식으로 시험합니다.

## 2. 칸(cell) = 추세 T × 타이밍 O × 봉 대응 M × 청산 X

### 추세 T (상위 봉, 마지막으로 **닫힌** 상위 봉 값; 9개)
| 이름 | 정의 (+1 상승 / -1 하락 / 0 없음) |
|---|---|
| OBV20 | OBV > OBV의 20봉 단순평균 → +1, < → -1 (`c_VO1_OBV_X_MA20`와 같아야 함) |
| OBV30 | OBV vs 30봉 평균 (추세판단 봇 OBV 판단 = `c_OBV_S`와 같아야 함) |
| OBV50 | OBV vs 50봉 평균 |
| OBVSL10 | OBV 기울기: OBV(지금) − OBV(10봉 전)의 부호 |
| ST | 슈퍼트렌드(10, 3) 방향 (`c_V39_ALL`) |
| EMA21_52 | EMA21 vs EMA52 (pine_ema) |
| ICHI | 종가가 구름 전체 위(아래) 그리고 AO > 0 (< 0) (`c_N12_ICHI_AO`, 추세판단 봇 N12) |
| J3 | 추세판단 봇 4표 중 3표, 유지 판단 (`j_dir`) |
| J3A | J3 그리고 상위 봉 ADX ≥ 20 (추세판단 봇의 '힘' 조건) |

OBV = `pine_indicators.obv(종가, 거래량)`. 상위 봉 예열: 상위 봉 번호 300 미만은 0(진입 안 함).

### 타이밍 O (진입 봉, 그 봉 마감에 앎; 6개)
| 이름 | 롱 / 숏 |
|---|---|
| SRSI_KD | 스톡RSI(14,14,3,3) K가 D를 위로 교차하고 K < 20 / 아래로 교차하고 K > 80 (= 라이브러리 `O4_STOCHRSI_ZONE`) |
| SRSI_X | 스톡RSI(14,14,3,3) K가 20을 아래→위로 교차 / 80을 위→아래로 교차 (과매도·과매수 '탈출') |
| RSI | RSI14가 30을 위로 / 70을 아래로 교차 (`O1_RSI14_REV30`) |
| WR | 윌리엄스 %R(14)이 -80을 위로 / -20을 아래로 교차 (`O6_WR14`) |
| CCI | CCI(20)가 -100을 위로 / +100을 아래로 교차 (`O5_CCI20`) |
| MFI | MFI(14)가 20을 위로 / 80을 아래로 교차 (`O7_MFI14`) |

신호 = 타이밍 신호의 방향 s 와 추세 T 의 값이 같을 때만(추세 0이면 진입 안 함). 진입 = 봉 마감 직후 1분봉 시가. 진입 봉 예열 300봉.

### 봉 대응 M (5개)
15분→1시간, 15분→4시간, 30분→1시간, 30분→4시간, 1시간→4시간.

### 청산 X (4개, 모두 1분봉으로 걷기, 비용 왕복 0.124%, 페이백 미포함)
| 이름 | 내용 |
|---|---|
| w35 | 주인님 실거래: 35배, 순ROE −50% 손절, 계단(+12 → +10 잠금, 이후 5%마다) |
| w35s30 | 같은 것, 순ROE −30% 손절 (이 연구에서 새로 계산, `frdeep.walk3`) |
| w35s20 | 같은 것, 순ROE −20% 손절 |
| a2 | 진입 봉 ATR14 × 2 가격 손절 + 같은 계단, 30배 |

**본 묶음(family) F = 9 × 6 × 5 × 4 = 1,080칸.** 친구 매매법 자체(묶음 A) = OBV 4개 × 스톡RSI 2개 × 5 × 4 = 160칸 (F의 일부).

### 미리 정한 '친구 그대로' 칸 (고르기 없음, 다중성 보정은 둘 사이 Holm)
- L1 = OBV30(1시간) 추세 + 30분 SRSI_KD, w35 — 친구 말 "30분봉 진입이면 1시간봉 추세" 그대로.
- L2 = OBV30(4시간) 추세 + 1시간 SRSI_KD, w35.

### 탐색용 묶음 C (부가, 따로 BH): 지표로 빨리 나가기
OBV 4개 × 스톡RSI 2개 × 5 대응 = 40칸, 청산 w35x = w35 + **첫 잠금 전에** (a) 진입 봉에서 반대 타이밍 신호가 나오거나
(b) 상위 봉이 닫혔을 때 그 칸의 추세 값이 반대(−s)이면 다음 분 시가에 청산(`walk3`의 flag). 친구가 손으로 지표를 보고 나갔을 수 있어서.

## 4. 통계와 고르기 규칙
- 칸의 행 = 그 칸의 모든 신호(한 포지션 규칙 없이, 각 신호를 따로). 값 = 신호 방향의 순 ROE(레버리지 × 순 가격 수익).
- 동전 쌍둥이 = 같은 진입의 반대 방향(`_opp`). d = ROE − 반대 ROE.
- 표준오차 = UTC 날짜로 묶은 군집 표준오차. t_abs = 평균 ROE / SE (H0: 평균 ≤ 0), t_d = 평균 d / SE (H0: 동전과 같음). 한쪽 p.
- 비교 대조: (1) 동전 쌍둥이, (2) 추세만 = 진입 봉 **모든** 마감에서 추세 방향으로 들어갔을 때(타이밍 없이; 같은 T·M·X), (3) 타이밍만 = 추세
  없이 그 타이밍 신호 전부, (4) 추세 반대 = 타이밍 신호가 추세와 반대일 때.
- **고르기(SEL만 봄):** n ≥ 200, 평균 ROE > 0, d > 0 인 칸 중 p_abs로 F 전체 1,080칸 BH(q = 0.10)를 통과한 칸. 많으면 t_abs 상위 10칸.
  하나도 없으면 "유의하지 않은 최선" 으로 t_abs 상위 5칸을 골라 똑같이 확인(유의하지 않다고 표시).
- 동전 대비 방향 실력: p_d로 BH(q = 0.10), 그리고 **전체 탐색 순열 검정**(SEL, 날짜 단위로 방향을 뒤집는 부호 순열 2,000번,
  1,080칸의 최대 t_d 분포로 Westfall-Young 보정 p).
- **확인(CONF, 한 번):** 고른 칸마다 평균 ROE > 0 이고 Holm 보정 한쪽 p < 0.05 (고른 칸 수로), 그리고 d > 0 이면 '확인됨'.
- 확인된 칸(없으면 최선 칸과 L1·L2, '확인 안 됨' 표시)에 대해: PRE·YTD·FWD 읽기, 한 포지션 계좌(6코인 합, 증거금 10/20/40%),
  거래당 순 ROE, 하루 거래, 최대 낙폭, 목표 길(30일 +500% = 6배에 필요한 증거금 × 레버리지; 날짜 블록 부트스트랩으로
  P(30일 안 6배), P(먼저 −50%), P(먼저 −90%)), 페이백 넣은 값 따로.
- 마지막 19일 운 읽기: 같은 기간 '추세만' 대조와 숏 비율, 동전 쌍둥이; FWD에서 가장 좋았던 칸 5개를 SEL·CONF에서 거꾸로 읽어
  '19일로 고르면 어떻게 되나'를 보여 줌(고르기에는 안 씀).
