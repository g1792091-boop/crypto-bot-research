# 봇 하나로 합치기: 어떤 멤버를 넣을까 (10/25)

두 분 계획: 지금 추세판단 봇처럼 **봇 하나(멤버 여러 개, 한 번에 포지션 하나)**를 돌림.
자료: 규칙봇 19일(10/06~10/24)의 모든 신호 47,984개를 규칙봇 청산(2 ATR 손절 + 계단 익절, 규칙봇 비용)으로 다시 계산한 것(`../combos/signals_sim.csv.gz`). 멤버 = 매매법@봉 × (양방향 / 숏만 / 롱만). 한 지갑·한 포지션, 노출 12배(증거금 40% × 30배)로 지갑을 계산했습니다.

## 2. 정직한 확인: 한 기간에서 고르고 다른 기간에서 봄 (노출 12배)

| 고른 기간 → 확인 기간 | 방법 | 확인 기간 결과 |
|---|---|---|
| 앞 절반 → 뒤 절반 | ① 같은 방식 최적 고르기 | 앞 절반 ×18.2 → **뒤 절반 ×0.17** |
| 뒤 절반 → 앞 절반 | ① 같은 방식 최적 고르기 | 뒤 절반 ×28.4 → **앞 절반 ×0.36** |
| 앞 절반(두 4분기) → 뒤 절반 | ② 두 4분기 모두 플러스 상위 3 / 5 / 8 / 전부 | ×0.63 / ×0.40 / ×1.03 / ×0.35 |
| 뒤 절반(두 4분기) → 앞 절반 | 같음 | ×0.91 / ×1.42 / ×1.52 / ×3.64 |
| 앞 절반 → 뒤 절반 | V39 + 숏 전용 상위 3 / 5 | ×0.77 / ×0.71 |
| 뒤 절반 → 앞 절반 | 같음 | ×1.06 / ×0.99 |
| 두 기간 모두 | V39 혼자 | ×1.94 / ×1.93 |
| 비교 | 아무 멤버 5개 (300번) 가운데 / 상위 10% | ×0.40~0.45 / ×0.95~1.16 |

- 19일 결과를 보고 고른 "최적 조합"은 다른 기간에서 무너졌습니다. **①은 쓰지 않는 것이 맞습니다.**
- 멤버를 더 넣으면 거래는 늘지만, 한 포지션이라 그 멤버들이 V39 자리를 막습니다. 다른 기간에서 보면 대부분 V39 혼자보다 나빴습니다.
- 두 기간 모두에서 꾸준했던 것은 **V39 혼자**입니다(단, V39도 19일 전체를 보고 고른 이름입니다).

## 3. 걸리는 점
- 모든 좋은 결과가 **하락장 숏**입니다(6코인 평균 −14%). 시장이 오르면 숏 멤버가 가장 크게 다칩니다.
- 이 표는 규칙봇 청산 기준입니다. 합친 봇을 30배로 고정하면 잠금 자리가 가격으로 약간 가까워져 결과가 조금 달라집니다.
