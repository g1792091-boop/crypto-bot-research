코인 선물 터미널 - 실행 방법 (파이썬 설치 불필요)
=====================================================

[Windows]
1. CoinFuturesTerminal.exe 를 더블클릭합니다.
2. "Windows의 PC 보호" 파란 창이 뜨면 → "추가 정보" → "실행" 을 누릅니다.
   (서명되지 않은 개인 제작 프로그램이라 처음 한 번 뜨는 경고입니다)
3. 검은 창이 뜨고 잠시 후 브라우저가 자동으로 열립니다.
   안 열리면 검은 창에 나온 주소(예: http://127.0.0.1:8000)를 브라우저에 직접 입력하세요.
4. 끝낼 때는 검은 창을 닫으면 됩니다.

[Mac]
1. 압축을 푼 폴더에서 CoinFuturesTerminal 을 마우스 오른쪽 클릭 → "열기" → "열기".
   ("확인되지 않은 개발자" 경고는 처음 한 번만 이렇게 넘기면 됩니다)
   그래도 막히면 터미널에서:  xattr -dr com.apple.quarantine 폴더경로
2. 터미널 창이 열리고 브라우저가 자동으로 열립니다.

[API 키 넣기 (선택)]
- 같은 폴더의 settings.txt 를 메모장으로 열어 '=' 뒤에 키를 붙여넣고 저장 → 프로그램을 껐다 켜면 적용됩니다.
- 무료 AI (Gemini): https://aistudio.google.com/apikey 에 구글 계정으로 들어가 "Create API key" →
  나온 키를 GEMINI_API_KEY= 뒤에 붙여넣기. 오른쪽 위에 "Gemini" 가 초록색으로 뜨면 연결된 것입니다.
  무료 등급은 분당 약 10회 제한이 있어 AI 분석팀 실행에 30초~1분 정도 걸릴 수 있습니다.
- 유료 AI (Claude): ANTHROPIC_API_KEY= 뒤에 키. 둘 다 넣으면 Claude 를 씁니다 (LLM_PROVIDER=gemini 로 바꾸면 Gemini).
- CoinGlass: COINGLASS_API_KEY= 뒤에 키.
- 키가 없어도 모든 화면이 동작합니다 (AI는 규칙 기반, 파생 데이터는 바이낸스 무료 데이터).

[사용 팁]
- 코인 바꾸기: 왼쪽 '관심 종목' 검색칸에 BTC, pepe, 도지, 에이다 처럼 영문·한글 이름을 치고 Enter.
  (바이낸스 선물에 없는 종목이면 차트가 비고 '없는 종목' 알림이 뜹니다)
- 차트 전체 화면: 차트 오른쪽 위 네모 버튼 또는 키보드 F (Esc 로 해제)
- 알림: 오른쪽 위 종 아이콘 → 원하는 알림 선택. "바탕화면 알림"을 켜면 브라우저가 권한을 물어봅니다.
  알림은 이 프로그램 화면(브라우저 탭)이 열려 있을 때만 옵니다.
- 청산맵 · 고래맵 · 봇 매매: 차트 위 버튼으로 켜고 끕니다. 고래 체결은 프로그램이 켜져 있는 동안 모입니다.
- 모의 주문 후 차트에 진입가·손절·익절·강제청산 선이 뜹니다. 손절·익절 선은 마우스로 끌어서 옮기거나,
  아래 '포지션' 표에서 가격을 입력해 바꿀 수 있습니다.
- 지지·저항: 여러 번 부딪힌 가격대를 자동으로 찾아 색 띠로 표시하고, 추세선도 자동으로 그립니다 ("지지·저항" 버튼).
- 보조지표: 차트 위 "지표 +" → 원하는 지표를 누르면 추가 (123종, 개수 제한 없음). 값은 오른쪽 목록에서 바꿉니다.
  검색칸에 한글·영문(예: 다이버, tema, 볼륨)으로 찾을 수 있고, 이름에 마우스를 올리면 설명이 나옵니다.
  '신호 · 패턴'(골든/데드 크로스, UT Bot, 샹들리에, RSI 다이버전스, 지그재그 등)은 차트에 화살표로 표시됩니다.
- 예측: 트레이드 화면 오른쪽 '예측' 탭 — 과거에 지금과 비슷했던 차트들의 이후 흐름(차트의 주황 부채꼴)과
  다음 봉 상승 확률(차트 오른쪽 흐린 캔들). 최근 적중률이 '찍기 기준'보다 높지 않으면 믿지 마세요.
- 퀀트 탭:
  · 순환매 — 비트코인 대비 어떤 코인·그룹이 강해지는지(RRG 그래프), 지금 순환 단계, 순환매 전략 백테스트
  · 시그널 스캐너 — 고른 코인·봉을 30초마다 자동 분석해 신호가 나면 알림 (종 → '시그널 스캐너'로 켜고 끔)
  · 리스크 — 코인 간 상관관계, 하루 최대 예상 손실(VaR), 몬테카를로, 파라미터 민감도, 포지션 크기 계산기
- 봉 마감 카운트: 가격축의 현재가 아래에 이번 봉이 끝나기까지 남은 시간이 표시됩니다 ("마감 카운트" 버튼으로 끄고 켬).
- 멀티 차트: 차트 오른쪽 위 "분할 1 · 2 · 4". 각 칸에서 코인과 봉을 따로 고를 수 있습니다.
- 전략 대화: '전략 · 백테스트'에서 전략을 말로 설명한 뒤, 고칠 점을 계속 말하면 됩니다.
  "알아서 개선해줘"라고 하면 손실 원인을 분석해 검증을 통과한 개선만 적용합니다.
- 코인·봉 바꾸기: '결과' 칸 맨 위 "대상"에서 코인(예: 이더, 솔라나, pepe)과 봉(1분~월봉)을 고르면
  그 코인·봉으로 다시 백테스트합니다. 자동 개선과 "페이퍼 봇 시작"도 이 대상으로 돌아갑니다.
  대화로 "도지 4시간봉으로 바꿔"라고 해도 됩니다.
- 여러 코인·봉 한꺼번에: "여러 코인 · 여러 봉 한꺼번에 테스트"를 펼쳐 코인과 봉을 고르고 실행하면
  성적순 표가 나옵니다. 줄마다 [보기] [개선] [봇 시작] 버튼이 있고, 수익 상위 3개를 한 번에 봇으로 돌릴 수도 있습니다.

[참고]
- 모의 계좌와 페이퍼 봇 기록은 같은 폴더의 state 폴더에 저장됩니다. 초기화하려면 state 폴더를 지우세요.
- 오른쪽 위에 주황색 "가상 데이터" 가 보이면 바이낸스 접속이 안 되는 것입니다 (회사망/VPN 확인).
  이때 보이는 차트와 백테스트는 가짜 데이터입니다.
- 트레이딩뷰 차트가 안 보이면 광고 차단 확장 프로그램을 꺼 보세요.
- 이 프로그램은 실거래 주문을 하지 않습니다. 모든 매매는 모의(페이퍼)입니다.
