GH Quant - 실행 방법 (파이썬 설치 불필요)
=====================================================

[Windows]
1. GHQuant.exe 를 더블클릭합니다.
2. "Windows의 PC 보호" 파란 창이 뜨면 → "추가 정보" → "실행" 을 누릅니다.
   (서명되지 않은 개인 제작 프로그램이라 처음 한 번 뜨는 경고입니다)
3. 잠시 후 GH Quant 가 자체 PC 앱 창으로 열립니다 (인터넷 창·검은 창 없음, 작업표시줄에 GH Quant 아이콘).
   윈도우 10·11 에 기본으로 들어 있는 WebView2(엣지 엔진)로 그립니다. 아주 옛 PC 라 WebView2 가 없으면 엣지 앱 창으로 대신 엽니다.
   뉴스·유튜브 같은 바깥 링크는 기본 브라우저로 열립니다. GHQuant.exe 를 다시 누르면 같은 프로그램에 창만 하나 더 뜹니다.
4. 끝낼 때는 앱 창을 닫으면 됩니다 ("끌까요?" → 끄기). 닫으면 AI 사무실 · 자동 분석도 멈추니, 계속 돌리려면 최소화(—)하세요.
   문제가 생기면 같은 폴더의 state/GHQuant.log 에 기록이 남습니다.
   평소 브라우저 탭으로 쓰고 싶으면 settings.txt 의 APP_WINDOW=0.

[Mac]
1. 압축을 푼 폴더에서 GHQuant 앱을 마우스 오른쪽 클릭 → "열기" → "열기". (자체 앱 창으로 열립니다)
   ("확인되지 않은 개발자" 경고는 처음 한 번만 이렇게 넘기면 됩니다)
   그래도 막히면 터미널에서:  xattr -dr com.apple.quarantine 폴더경로
2. settings.txt 와 state 폴더는 GHQuant 앱 옆에 생깁니다.

[API 키 넣기 (선택)]
- 같은 폴더의 settings.txt 를 메모장으로 열어 '=' 뒤에 키를 붙여넣고 저장 → 프로그램을 껐다 켜면 적용됩니다.
- 무료 AI (Gemini): https://aistudio.google.com/apikey 에 구글 계정으로 들어가 "Create API key" →
  나온 키를 GEMINI_API_KEY= 뒤에 붙여넣기. 오른쪽 위에 "Gemini" 가 초록색으로 뜨면 연결된 것입니다.
  무료 등급은 분당 약 10회 제한이 있어 에이전트 팀 회의에 몇 분 걸릴 수 있습니다.
- 무료 AI (NVIDIA): https://build.nvidia.com 에 로그인 → 아무 모델 페이지에서 "Get API Key"
  → nvapi- 로 시작하는 키를 NVIDIA_API_KEY= 뒤에 붙여넣기. 오른쪽 위에 "NVIDIA" 가 초록색으로 뜨면 연결된 것입니다.
  NVIDIA_MODEL= 을 비워 두면 이 키로 쓸 수 있는 모델 중에서 자동으로 고릅니다. NVIDIA 는 모델을 수시로 종료하는데
  (오류 410 "end of life"), 그러면 그 모델을 기억해 두고 다른 모델로 알아서 바꿔 씁니다.
  특정 모델을 쓰려면 NVIDIA_MODEL= 뒤에 모델 이름을 그대로 (예: deepseek-ai/deepseek-v3.1, qwen/qwen3-235b-a22b).
  가입 크레딧과 분당 약 40회 제한이 있습니다. 크레딧이 떨어지면 AI 기능이 자동으로 규칙 분석으로 바뀝니다.
- 여러 AI 모델 쓰기: 오른쪽 위 AI 표시(예: "NVIDIA")를 누르거나, 에이전트 팀·오토파일럿 화면의 "🧠 AI 모델" 버튼 → 'AI 모델 설정' 창
  1) API 키: NVIDIA·Gemini·Claude 키를 여기서 넣으면 바로 적용되고 settings.txt 에도 저장됩니다.
  2) 내 모델 목록: 공급자를 고르고 모델 이름을 넣어 "추가" (NVIDIA 는 "모델 목록 불러오기"로 쓸 수 있는 모델 이름 추천). "테스트"로 바로 확인.
  3) 기본 모델과 대체 순서: 모델이 한도·오류로 실패하면 대체 순서의 다음 모델로 자동으로 넘어갑니다 (NVIDIA → Gemini 처럼 섞어도 됨).
  4) 기능별 모델: 실시간 AI · 오토파일럿 · 전략 대화 · 뉴스 · 차트 코멘트 · 에이전트 팀(판단형/반복형)마다 다른 모델.
  5) 에이전트별 모델: 23명 각각 다른 모델 (예: 전략가·리스크 책임자 = deepseek-v3.1, 시장분석가 = llama-3.1-8b).
  무료 한도를 아끼려면 자주 부르는 반복형 에이전트에 가벼운 모델, 판단형에 큰 모델을 추천합니다.
- 오토파일럿의 AI: 설정에서 "AI 가 매매법 후보 제안"을 켜면(기본 켜짐) 탐색 때마다 AI 가 차트 지표로 매매법을 몇 개 직접 만들고,
  규칙 후보와 똑같이 3구간 검증을 거칩니다 (🤖 표시). "진입 시그널마다 AI 코멘트"를 켜면 오토 봇이 진입할 때 근거와 위험을 알림으로 받습니다.
- 유료 AI (Claude): ANTHROPIC_API_KEY= 뒤에 키. 여러 개 넣으면 Claude → NVIDIA → Gemini 순서로 씁니다
  (LLM_PROVIDER=nvidia 나 gemini 로 바꾸면 그것을 씁니다).
- CoinGlass: COINGLASS_API_KEY= 뒤에 키.
- 키가 없어도 모든 화면이 동작합니다 (AI는 규칙 기반, 파생 데이터는 바이낸스 무료 데이터).

[AI 사무실 — 31개 팀 321명이 24시간 일함]
- 위쪽 'AI 사무실' 탭. 팀마다 팀장 1명 + 팀원이 있고, 자리에서 차트·뉴스를 보고(말풍선), 정해진 일을 돌아가며 하고, 회의합니다.
- 질문: 오른쪽 아래 칸에 쓰고 '보내기'. 위의 방(#비트코인팀 등)을 고르면 그 팀이 먼저 답합니다. @이름 으로 특정 직원을 부를 수 있습니다.
- 팀 업무 시키기: 팀 상자 오른쪽 위 ▶ 버튼, 또는 위쪽 '팀 업무 시키기 ▾'.
- 매매법 파이프라인 탭: 매매법 개발팀 → 백테스트팀 → 데모거래팀 → 실거래 승인 대기 → (내가 승인) 실거래. 커스텀 지표도 같은 흐름.
- 실거래 탭: 기본 꺼짐 · 기본 테스트넷(가짜 돈). settings.txt 에 BINANCE_API_KEY / BINANCE_API_SECRET (선물 권한만, 출금 권한 금지)을 넣고,
  화면에서 '실거래 켜기' 확인 문구를 입력하고, 매매법마다 '승인'을 눌러야 주문이 나갑니다. 한도(주문 금액·전체·레버리지·하루 손실)와 🛑 비상 정지가 있습니다.
- 진입 봇 탭: 트레이드 화면의 시나리오(박스권·돌파·이탈·눌림) 중 정책이 고른 것으로 시나리오 봇이 계속 가상 진입합니다 (진입 에이전트팀).
  진입 전에 보조지표 · 147종 합의 · 내 차트에 켜 둔 지표를 확인하고, 과거 차트로 실제 적중률을 배우고, 6시간마다 스스로 규칙을 고칩니다(나아질 때만).
  ※ 화면의 % 는 추정값이라 실제 적중률과 다릅니다. 트레이드 화면 시나리오마다 '배운 실제 적중률'이 함께 나옵니다.
  가상 성적이 기준을 넘으면 실거래 탭에 승인 대기로 올라가고, 사람이 승인해야만 실거래 한도 안에서 따라 주문합니다.
  레버리지(1~20배)와 주문당 증거금(%)을 직접 바꿀 수 있고, 보유 중인 포지션은 실시간 수익률(증거금 대비 %)이 나옵니다.
  '내가 보는 차트 분봉에서 돌기'를 켜 두면 트레이드 화면에서 보고 있는 코인·분봉으로 판단합니다.
  트레이드 차트에 봇의 진입(주황 화살표)·청산·대기 주문선·보유 중 손절/목표/청산가와 실시간 수익률이 표시됩니다 (오버레이 → 시나리오 봇).
  주문이 없어도 차트 왼쪽 위와 시나리오 패널 맨 위에 '🤖 시나리오 봇 …' 한 줄로 지금 무엇을 하는지(판단 중·건너뛴 이유·다음 판단 시각·학습 진행)가 보입니다.
  화면 위 GH QUANT 옆의 작은 글자가 빌드 번호입니다 (새로 받은 앱인지 확인용).
  진입 봇 탭의 '지금 판단 중인 코인·봉' 표에서 왜 진입했는지/건너뛰었는지와 다음 판단 시각을 볼 수 있습니다.
- 1억 점검 탭: '한 달 10만 원 → 1억' 같은 목표가 실제 성적으로 얼마나 가능한지 계산합니다 (1억 챌린지 검증팀).
  베팅 크기(레버리지)마다 목표 도달 확률과 파산 확률, 켈리 기준 베팅, 현실적으로 걸리는 기간이 나옵니다.
  아래 버튼으로 그리드 매매 · 펀딩비 차익 점검, 깃허브 오픈소스에서 옮긴 기법 목록을 봅니다.
  한 달 1000배는 매일 +25.9%를 30일 연속 내야 하는 수준이라, 레버리지를 올리면 파산 확률이 먼저 올라갑니다.
- 지표 타점 탭: '터미널 지표 추세·타점팀'이 코인분석 터미널의 보조지표 147종을 모두 계산해 합친 추세 점수(15분·1시간·4시간·일봉)와
  진입·손절·목표(손익비 1.5 이상일 때만)를 실시간으로 보여 줍니다. 60초마다 코인 하나씩 돌고, 새 타점은 차트 'AI 시그널'과 알림으로도 나옵니다.
  '지금 계산'으로 바로 돌리고, 기록은 state/office/files/termind/ 에 CSV 로 쌓입니다.
- AI 배정 탭 (직원에게 AI 키 배정하는 법):
  ① AI 사무실 → 오른쪽 'AI 배정' 탭 → NVIDIA/Gemini/Claude 칸에 키를 붙여넣고 '넣기' (1번 = 기본, 2~9번 = 추가 키).
     처음 넣으면 팀마다 자동으로 골고루 배정됩니다. 키는 settings.txt 에도 저장돼 다음 실행에도 그대로입니다.
  ② 팀을 바꾸려면 팀 줄의 '배정 모델' 칸에 nvidia#2:auto 처럼 적고 '저장'. 직원 한 명만 바꾸려면 ▸ 를 눌러 펼친 뒤 그 사람 칸에.
  ③ 확인: '실제로 답한 AI (오늘)' 칸과 직원 캐릭터를 눌렀을 때 '실제로 답한 AI' 에 진짜로 답한 키·모델과 횟수가 나옵니다.
     '아직 없음'이면 아직 그 직원 차례가 안 온 것이고, '실패'면 키가 틀렸거나 한도에 걸린 것입니다(이유가 같이 나옴).
  무료 키는 분당 한도가 키마다 따로라 여러 개를 나눠 쓰면 덜 막힙니다.
- 결과·다운로드 탭: 모든 결과가 저장되는 폴더 경로가 나옵니다 (실행 파일 옆 state/office/files).
  파일 이름을 누르면 받고, '전체 ZIP 받기'로 한 번에 받고, '폴더 열기'로 탐색기에서 엽니다. CSV 는 엑셀에서 바로 열립니다.
- 설정 ▾: 자동 회의 간격, 팀 업무 간격, 하루 AI 호출 한도(기본 1,500번) 등을 바꿉니다.

[사용 팁]
- 화면 배치는 트레이딩뷰와 같습니다 (직접 만든 차트 — 트레이딩뷰를 가져다 쓰지 않음).
  위: 종목 · 봉 · 차트 종류 · 지표 · 오버레이 · 알림 · 레이아웃 · 되돌리기 · 스크린샷 · 전체 화면
  왼쪽: 그리기 도구 (추세선 Alt+T · 수평선 Alt+H · 수직선 Alt+V · 피보나치 Alt+F · 사각형 Alt+R · 롱/숏 박스 · 텍스트 · 브러시 등)
        그린 것은 클릭해서 고르고 끌어서 옮기고, Delete 로 지우고, Ctrl+Z / Ctrl+Y 로 되돌립니다.
  오른쪽 아이콘: 관심종목 · AI 알림/채팅 · AI 분석 · 시나리오 · 예측 · 풋프린트 · 호가 · 알림 · 연구 · 객체 트리
  아래: 1D~ALL 범위, % · log 스케일 / AI 시그널 성과 · 전략 시그널 · 스크리너 · 거래소 시세 · 뉴스 · 알림 기록
- 코인 바꾸기: 차트에서 아무 글자나 치거나 왼쪽 위 종목 이름을 눌러 검색 (BTC, pepe, 도지, 에이다 처럼 영문·한글). 
  (바이낸스 선물에 없는 종목이면 차트가 비고 '없는 종목' 알림이 뜹니다)
- 차트 전체 화면: 차트 오른쪽 위 네모 버튼 또는 키보드 F (Esc 로 해제)
- 알림: 오른쪽 위 종 아이콘 → 원하는 알림 선택. "바탕화면 알림"을 켜면 브라우저가 권한을 물어봅니다.
  알림은 이 프로그램 화면(브라우저 탭)이 열려 있을 때만 옵니다.
- 청산맵 · 고래맵 · 봇 매매: 차트 위 버튼으로 켜고 끕니다. 고래 체결은 프로그램이 켜져 있는 동안 모입니다.
- 수동 주문 · 모의 계좌는 없습니다. AI 시그널과 전략 시그널은 실제 시세에서 '가상 체결'로 채점되어
  아래 'AI 시그널 성과' · '전략 시그널' 탭에 적중률 · 평균 R · 가상 수익률로 쌓입니다.
- 연구: 오른쪽 '연구' 탭 — 다른 연구에서 약 3,500개 셋업을 백테스트한 결과 카드 43장과, 이 앱 AI 시그널의 실제 성적.
  모든 AI(분석 · 에이전트 팀 · 자동 분석 · 오토파일럿)가 이 내용을 읽고 판단합니다. 연구 결론: 확인 구간을 통과한 셋업은 0개.
- 지지·저항: 여러 번 부딪힌 가격대를 자동으로 찾아 색 띠로 표시하고, 추세선도 자동으로 그립니다 ("지지·저항" 버튼).
- 보조지표: 차트 위 "지표 +" → 원하는 지표를 누르면 추가 (147종, 개수 제한 없음). 값은 오른쪽 목록에서 바꿉니다.
  검색칸에 한글·영문(예: 다이버, tema, 볼륨)으로 찾을 수 있고, 이름에 마우스를 올리면 설명이 나옵니다.
  '신호 · 패턴'(골든/데드 크로스, UT Bot, 샹들리에, RSI 다이버전스, 지그재그 등)은 차트에 화살표로 표시됩니다.
