# GH Coin 을 Vultr VPS 에서 24시간 돌리기 (Ubuntu 24.04)

GH Coin 은 **브라우저 창 안에서 돌아가는 봇**이라, 서버에 가상 화면을 만들고 그 안에서 Chrome 으로 띄웁니다.
보는 곳은 **주소 하나** — Tailscale 을 켜고 `http://<tailscale IP>:8080/` 을 열면 봇 화면이 그대로 내 브라우저에 그려집니다
(사무실 · 직원 · 말풍선 · 채팅 · 버튼 · 확인 창 전부). 그림을 보내는 원격화면이 아니라서 **선명하고 부드럽고**, 누르기 · 입력 · 승인도 됩니다.

> 다른 봇(paperbot)과는 **다른 서버**에 설치하세요. 서로 영향이 없습니다.

## 1. 서버 만들기 (Vultr)

| 항목 | 고를 것 |
|---|---|
| 종류 | Cloud Compute – Shared CPU → **High Performance**(AMD 또는 Intel) |
| 사양 | **2 vCPU / 4 GB** (Regular 도 되지만 CPU 가 느림) |
| 위치 | **Seoul** (미국 지역 X — 바이낸스가 미국 IP 를 막음) |
| OS | **Ubuntu 24.04 LTS x64** |

## 2. 설치 (명령 2줄, 약 10분)

SSH(Termius 등)로 `root` 접속 후:

```bash
curl -fsSLo install-ghcoin.sh https://raw.githubusercontent.com/g1792091-boop/crypto-bot-research/claude/vigilant-shannon-irq1vg/vps/install-ghcoin.sh
sudo bash install-ghcoin.sh '구글 드라이브 공유 링크'
```

- 구글 드라이브 zip 공유는 설치하는 동안만 **링크가 있는 모든 사용자** 로 두면 됩니다. 끝나면 다시 **제한됨** 으로.
- 마지막에 **Tailscale 로그인 주소**가 나오면 열어서 다른 봇 서버와 **같은 계정**으로 로그인하세요.
- 끝나면 화면에 **접속 주소**와 **로그인 비밀번호**가 나옵니다.

## 3. 화면 보기 (:8080)

Tailscale 켜고 → `http://<tailscale IP>:8080/` → 비밀번호 → GH Coin 화면 (PC · 휴대폰 모두)

- 봇 화면을 그대로 옮겨 와 **내 브라우저가 직접 그립니다** (CSS 로 창에 맞춤 → 글자가 선명). 사무실 · 채팅 글꼴도 서버의 봇과 같은 파일(나눔고딕코딩)을 받아 써서 줄바꿈이 똑같습니다.
- 휴대폰은 **실제 크기**(1:1, 끌어서 봄)로 열립니다. 봇 화면 가운데에 창(AI 연결 · 지갑 · 직원 카드 · **실거래 승인**)이 뜨면 그쪽으로 저절로 옮겨 보여 주고,
  승인 창을 놓쳤으면 위에 **"🔔 주문 승인 대기 — 보기"** 띠가 뜹니다. 가로로 돌리면 전체가 보입니다 (메뉴 → 화면에 맞추기).
- 누르기 · 글자 입력(한글 포함) · 목록 고르기 · 스크롤 · Esc/Enter · 봇의 확인 창(예/아니오)까지 봇에 그대로 전달됩니다. 실거래 **승인 창이 뜨면 탭 제목에 🔔**
  (승인 창에서 Esc = 거절, 앱과 같음).
- 왼쪽 아래 점(휴대폰은 ☰): 초록 **연결됨** · 노랑 **다시 연결 중 / 봇 응답 지연 / 봇 창 켜지는 중 / 다른 창에서 보는 중** · 빨강 **봇 멈춤 / 봇 창 연결 끊김**. 누르면 메뉴:
  **요약 화면**(숫자만, 휴대폰용 `/summary`) · **실제 크기** · **앱 새로고침**(사무실을 닫았거나 멈췄을 때) · **로그아웃**.
- 인터넷이 끊겼다 돌아오면 저절로 다시 붙습니다 (35초 넘게 아무 소식이 없으면 끊긴 것으로 봄). 끊긴 동안 누른 것은 6초 뒤 "보내지 못했습니다"로 알리고,
  10초 넘게 늦게 도착한 누름은 서버가 버립니다 (나중에 한꺼번에 봇에 들어가지 않게).
- 동시에 볼 수 있는 창(탭)은 4개까지입니다. 5번째를 열면 가장 오래된 창이 "다른 창에서 보는 중"으로 멈추고, 그 창의 **여기서 다시 보기**로 이어 볼 수 있습니다.
- 비밀번호: `sudo cat /root/ghcoin-대시보드-비밀번호.txt` · 새로 만들기: `sudo bash add-dashboard.sh --new-password` (다른 기기 로그인도 풀림). 로그인은 30일 유지.
- 비밀번호 칸 · API 키 칸의 값은 이 화면으로 `****` 로만 옵니다 (봇 안의 값은 그대로). 새 키는 그 칸을 눌러 붙여 넣으면 됩니다.
- Tailscale 안에서만 열리고, 그 안에서도 비밀번호가 있어야 합니다. **Tailscale Funnel 로 8080 을 인터넷에 열지 마세요.**

> GH Coin 주소(`127.0.0.1:17860`)를 내 PC 브라우저에서 직접 열면 **내 PC 에서 봇이 하나 더** 켜집니다. 꼭 위 주소로 보세요.

## 운영

| 할 일 | 명령 |
|---|---|
| 상태 · 메모리 보기 | `ghcoin-status` |
| 앱 창 새로 띄우기 | `sudo systemctl restart ghcoin-chrome` |
| 화면(:8080) 비밀번호 | `sudo cat /root/ghcoin-대시보드-비밀번호.txt` |
| 화면 서비스만 다시 켜기 | `sudo systemctl restart ghcoin-dash` |

- 앱 창을 닫거나 Chrome 이 죽어도 10초 뒤 다시 열립니다. 서버가 재부팅돼도 자동으로 켜집니다.
- 매일 새벽 5:15 에 앱 창을 새로 띄워 메모리를 비웁니다 (설정 · 기록은 브라우저 저장소에 그대로).
- 메모리가 바닥나면 Chrome 을 정리합니다 (earlyoom). 봇 탭만 죽어도('Aw, Snap') 감시(ghcoin-watchdog)가 3분 뒤 앱 창을 다시 띄웁니다. 2GB 스왑도 잡아 둡니다.
- **사양 올릴 때**: `ghcoin-status` 의 `남은메모리` 가 500MB 밑으로 자주 내려가면 Vultr 에서 8GB 로 Resize.

## 5. 실시간 화면은 어떻게 동작하나 (:8080)

`install-ghcoin.sh` 가 함께 설치합니다 (따로 넣거나 업데이트: `sudo bash add-dashboard.sh`).
이미 돌고 있는 서버에서 업데이트하면 글꼴 `fonts-nanum` 도 설치되는데, 봇 화면은 앱 창을 다시 띄운 뒤(매일 05:15, 또는 `sudo systemctl restart ghcoin-chrome`)부터 그 글꼴을 씁니다.

- 앱(친구 코드)은 바꾸지 않습니다. 앱 창(Chrome)에 이 서버 안에서만 열리는 통로(127.0.0.1:9222, 방화벽으로 `ghcoin` 계정만)를 켜고,
  그 통로로 페이지에 작은 기록기(rrweb, `vendor/` 에 버전 · 출처 · 해시 고정)를 넣어 **화면의 DOM 변화만** 보냅니다.
  평소 1초에 1KB 미만, 봇 CPU 부담은 측정상 차이 없음. 접속할 때 · 새로고침 뒤에만 화면 사진 한 장(약 2MB → 압축 약 0.15MB).
- 누른 것은 **화면에 보이는 그 버튼 · 칸에 사람이 하는 것과 같은 입력**으로만 전달합니다 (임의 코드 실행 없음). 모든 조작은 로그인 + 요청 확인 토큰이 필요합니다.
- 매일 05:15 앱 창 재시작 · Chrome 재시작 · 새로고침 뒤에도 저절로 다시 붙습니다 (몇 초).
- 봇에 확인 창(confirm)이 뜨면 이 화면에 같은 창이 뜹니다. **2분 동안 답이 없으면 '취소'** 로 닫아 봇이 멈춰 있지 않게 합니다.
  확인 창이 이미 떠 있는 동안 이 서비스가 다시 켜지면 그 창을 볼 수 없습니다 → 화면 위 띠에 "봇 페이지가 응답하지 않습니다 … 앱 새로고침"이 뜨고,
  2분 30초 넘게 그대로면 서비스가 앱을 한 번 새로고침해서 풉니다 (그냥 두면 감시가 Chrome 전체를 다시 띄움).
- 차트 터미널의 차트 그림은 1초에 한 번 그림으로 옵니다 — **화면에 보이는 실시간 창이 있을 때만**, 그림이 바뀌었을 때만 만듭니다 (차트를 끌기 · 그리기는 아직 안 됨 — 휠 확대 · 클릭은 됨).
- 봇이 내려받는 파일(학습 데이터 · 결과물)은 **서버의** Downloads 에 저장됩니다. 그때 이 화면에 "봇이 파일을 서버에 저장했습니다" 알림이 뜹니다.
- 실거래 · 차트 터미널을 닫으면 앱이 사무실을 다시 열지 않습니다 (앱 동작) → 화면 위 띠의 **다시 열기** 한 번이면 됩니다.
- 앱의 스타일 파일은 원본 그대로 받아서 씁니다 (`/app/…`, 그림 · CSS · 글꼴만, 앱의 `/__nuri` 는 절대 안 거침).

| 왼쪽 아래 표시 | 뜻 | 할 일 |
|---|---|---|
| 초록 "연결됨" | 정상 | — |
| 노랑 "봇 창 켜지는 중" | 05:15 재시작 · Chrome 재시작 직후 (약 35–50초) | 기다리면 돌아옴 |
| 노랑 "봇 응답 지연" | 백테스트 같은 무거운 일 중 (위에 '응답하지 않습니다' 띠가 함께 뜨면 확인 창 때문) | 기다리면 돌아옴 (띠가 있으면 띠의 앱 새로고침) |
| 노랑 "다시 연결 중" | 내 인터넷 · Tailscale 이 끊김 | 저절로 다시 붙음 |
| 노랑 "다른 창에서 보는 중" | 실시간 화면을 5개 넘게 열어서 이 창이 밀려남 | 이 창에서 **여기서 다시 보기** |
| 빨강 "봇 창 연결 끊김" | Chrome 이 꺼졌거나 다시 켜지는 중 | 저절로 돌아옴 (3분 넘으면 감시가 다시 띄움) |
| 빨강 **"봇 멈춤"** | 봇 탭이 죽음 · 확인 창이 떠서 멈춤 | 메뉴 → 앱 새로고침. 감시도 3분 뒤 다시 띄움 |

## 6. 서버용 보안 강화 (키 보호)

설치 스크립트는 **서버용 실행기를 빌드할 때만** 아래를 막습니다 (앱 코드 · PC 용 exe 는 그대로).
뉴스 · 웹 글에 숨은 악성 지시를 AI 가 따르더라도 서버의 키를 읽어 밖으로 보낼 수 없게 하기 위해서입니다.

- AI 직원이 서버에서 **명령어 실행** ✗ (보고서 · 기록 저장은 그대로 됨)
- 사무실 폴더 밖 파일 읽기 · 쓰기, 다른 폴더 열기 ✗
- AI 가 고친 파일로 **앱 코드 바꿔치기** ✗
- 127.0.0.1 · localhost 가 아닌 주소로 실행기 접속 ✗ (DNS 리바인딩 방지)
- API 중계를 서버 내부 주소로 보내기 ✗
- 실행기는 따로 된 계정(`ghcoin-srv`)으로 돌고, Chrome 저장소가 있는 `/home/ghcoin` 은 그 계정이 읽을 수 없음
