# 누리 AI — 내 기기에서 도는 나만의 AI

Claude, ChatGPT 같은 외부 AI 서비스나 API 키 없이 **브라우저 안에서 직접 AI 모델을 실행**하는 챗봇 + 대시보드입니다.
서버도 설치도 필요 없고, 대화·문서·설정은 모두 이 기기에만 저장됩니다.

## 동작 방식

- AI 엔진: [wllama](https://github.com/ngxson/wllama) (llama.cpp의 WebAssembly 버전, MIT). `vendor/wllama/`에 포함되어 있어 외부 CDN을 쓰지 않습니다.
- 가속: WebGPU가 있으면 GPU, 없으면 CPU(멀티스레드)로 실행합니다.
- 모델: 오픈소스 GGUF 모델. 처음 한 번 내려받으면 브라우저 저장소에 보관되어 이후에는 **인터넷 없이** 켜지고 답합니다.
- 오프라인: 서비스 워커가 앱 파일을 저장합니다. 한 번 열어 둔 뒤에는 비행기 모드에서도 열립니다.

## AI 두뇌

| 두뇌 | 어디서 도나 | 지능 | 비용 |
|---|---|---|---|
| 내 기기 AI | 이 컴퓨터 (브라우저) | 낮음 (1~2B) | 무료, 오프라인 |
| 고성능 오픈모델 | NVIDIA 클라우드 (Qwen3 235B, DeepSeek-R1, Llama 70B 등) | 높음 | 무료 한도, API 키 필요 |
| 내 PC 대형 모델 | 내 PC의 Ollama (7~30B) | 중간~높음 | 무료, 오프라인, 고사양 PC |

채팅, 코인 분석, 건축 설계가 모두 고른 두뇌를 씁니다. Claude·ChatGPT 같은 비공개 AI는 쓰지 않습니다.
외부 API(NVIDIA, 업비트, 바이낸스, Ollama)는 `NuriAI.exe`의 내장 중계로 연결되며, 웹 버전에서는 브라우저 보안정책 때문에 막힐 수 있습니다.

## 코인 트레이딩 룸

- 업비트(KRW)·바이낸스(USDT) 실시간 시세와 코인 목록
- 캔들 차트 (1분~주봉, 최대 1,000개), 이동평균 20/60/120, 볼린저 밴드, 거래량, RSI, MACD, 자동 지지·저항
- 퀀트 점수: 추세·모멘텀·거래량 지표를 점수로 합산 (-100~+100)
- AI 분석: 계산된 지표를 AI가 해석해 시나리오, 진입·손절·목표, 위험 요인, 확신도를 정리
- 전략 백테스트: 이동평균 크로스, RSI 역추세, 볼린저 회귀, MACD 크로스 (수수료·손절·익절 반영)
- 모의투자: 가상 계좌로 매수·매도 연습 (실제 주문 없음)

## 기능

|---|---|
| 채팅 | 스트리밍 답변, 마크다운·표·코드블록, 생각 과정 보기, 다시 생성, 질문 수정, 텍스트 파일 첨부 |

## 실행

### 가장 쉬운 방법: 실행 파일 (Windows)

`dist/NuriAI.exe`를 더블클릭하면 끝입니다. 설치도 명령어도 필요 없습니다.
exe 안에 앱 전체가 들어 있고, 내 컴퓨터 안에서만 동작하는 작은 서버가 앱 창(Edge/Chrome)을 열어 줍니다.
창을 닫으면 프로그램도 자동으로 꺼집니다. 자세한 내용은 `dist/사용법.txt`를 보세요.
실행 파일은 `launcher/build.sh`로 다시 만들 수 있습니다(Go 필요).

### 웹으로 열기

1. **GitHub Pages (설치 없음)**: 저장소 Settings → Pages → Source를 "Deploy from a branch"로, 브랜치를 선택하고 `/ (root)` 저장.
   몇 분 뒤 `https://<아이디>.github.io/<저장소>/nuri-ai/` 에서 열립니다. 휴대폰에서 "홈 화면에 추가"하면 앱처럼 쓸 수 있습니다.
2. 내 컴퓨터: 이 폴더에서 `python -m http.server 8000` 실행 후 `http://localhost:8000` 접속.
   (파일을 더블클릭해 `file://`로 열면 브라우저 보안 정책 때문에 AI 엔진이 켜지지 않습니다.)

## 완전히 외부와 끊고 싶다면

모델 파일도 직접 보관할 수 있습니다. Hugging Face에서 받은 `.gguf` 파일을

- "AI 모델 → 내 컴퓨터의 GGUF 파일"로 바로 열거나
- 내 서버(같은 GitHub Pages 저장소 등)에 올리고 "GGUF 파일 주소"로 불러오면 됩니다.

브라우저는 파일 하나를 2GB까지 읽을 수 있습니다. 더 큰 모델은 `llama-gguf-split --split-max-size 512M`으로 나눠서 쓰세요.

## 한계

- 브라우저에서 돌릴 수 있는 1~2B 크기 모델이라 ChatGPT·Claude 같은 대형 모델보다 지식과 정확도가 낮습니다.
- 인터넷 검색을 하지 않으므로 최신 정보는 모릅니다. 필요한 자료는 "내 지식"에 문서로 넣어 주세요.
- 첫 실행 시 모델 다운로드(0.4~1.6GB)가 필요합니다.
