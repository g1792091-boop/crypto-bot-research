# 누리 AI

Claude·Claude Code처럼 **채팅**과 **코드** 두 가지 모드로 무엇이든 하는 나만의 AI입니다.
Claude·ChatGPT 같은 비공개 AI는 쓰지 않고, 오픈소스 모델만 씁니다.

## 실행

`dist/NuriAI.exe`를 더블클릭하세요. 설치가 필요 없습니다. (자세한 내용: `dist/사용법.txt`)

## 채팅 모드

그냥 말하면 누리가 필요한 도구를 스스로 골라 씁니다.

| 이렇게 말하면 | 누리가 하는 일 |
|---|---|
| "비트코인 지금 분석해줘" | 업비트 시세·지표 계산 → 오른쪽 패널에 실시간 차트 |
| "이더리움 4시간봉 RSI 전략 백테스트해줘" | 과거 데이터로 전략 수익률·낙폭·승률 계산 |
| "100만원어치 비트코인 모의 매수해줘" | 가상 계좌로 모의투자 (실제 주문 없음) |
| "대지 60평에 3층 단독주택 설계해줘" | 3D·평면·인테리어 설계 + 건폐율·용적률·공사비, Revit/CAD/SketchUp 파일 |
| "할 일 관리 웹앱 만들어줘" | 결과물(웹페이지·코드·문서)을 오른쪽 패널에 표시·저장 |
| "내 문서에서 휴가 규정 찾아줘" | '내 지식'에 올린 문서 검색 |

## 코드 모드 (exe 전용)

내 컴퓨터의 폴더를 열면 누리가 파일을 살펴보고, 고치고, 명령을 실행합니다.
파일을 바꾸거나 명령을 실행하기 전에 바뀌는 내용(diff)을 보여 주고 허락을 구합니다.
권한: 매번 묻기 / 편집 자동 허용 / 모두 자동 허용.

도구: 목록·읽기·파일 찾기·내용 검색·쓰기·수정·명령 실행·할 일 목록. 작업 폴더 밖은 접근하지 않습니다.

## AI 두뇌 (입력창의 모델 버튼)

| 두뇌 | 지능 | 비고 |
|---|---|---|
| 내 기기 AI | 낮음 | 오프라인, 1~2B 소형 모델 (wllama = 브라우저 속 llama.cpp) |
| 고성능 오픈모델 | 가장 높음 | NVIDIA 무료 API 키 (Qwen3 235B, DeepSeek-R1, Llama 70B 등). 도구·코딩은 이걸 추천 |
| 내 PC 대형 모델 | 중간~높음 | Ollama로 7~30B 모델, 오프라인 |

## 구조

- `index.html` 화면 틀과 스타일, `app.js` 화면 동작
- `engine.js` 저장소·내 기기 AI·두뇌 연결·문서 검색·마크다운
- `agent.js` 도구 호출 규약(`<tool name="…">{…}</tool>`)과 도구 모음, 반복 실행
- `trade.js` 시세·지표·퀀트 점수·백테스트·트레이딩 룸
- `../launcher/` exe: 앱 내장, 외부 API 중계, 코드 모드 파일·명령 처리

## 한계

- 지능은 고른 모델에 달려 있습니다. 소형 모델은 도구 사용과 코딩을 잘 못합니다.
- 인터넷 검색은 하지 않습니다. 코인 시세는 업비트·바이낸스 공개 API로 받습니다.
- 투자 분석은 과거 데이터 기반이며 미래 가격을 보장하지 않습니다.
