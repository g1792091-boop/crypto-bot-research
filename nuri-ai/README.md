# GH Nano (누리 AI 앱)

모든 모델과 스킬을 하나로 묶은 **나만의 자체 AI**입니다. Claude·Claude Code처럼 **채팅**과 **코드** 두 가지 모드로 무엇이든 합니다.
AI 이름은 설정 → 맞춤 지침에서 바꿀 수 있습니다(기본 GH Nano).
Claude·ChatGPT 같은 비공개 AI는 쓰지 않고, 오픈소스 모델(무료 API 또는 내 컴퓨터)만 씁니다.

## 실행

`dist/GHNano.exe`를 더블클릭하세요. 설치가 필요 없습니다. (자세한 내용: `dist/사용법.txt`)

## AI 두뇌: 키만 붙여넣으면 자동 연결·자동 선택·자동 교체

설정 → **AI 두뇌 · API 키**에 무료 키를 붙여넣으면 접두어로 회사를 알아보고 모델 목록을 받아 둡니다.

| 키 | 회사 | 비고 |
|---|---|---|
| `nvapi-…` | NVIDIA (build.nvidia.com) | 대형 오픈모델 다수, 무료 한도. 이미지 렌더링에도 사용 |
| `gsk_…` | Groq | 매우 빠름, 무료 한도 |
| `csk-…` | Cerebras | 매우 빠름, 무료 한도 |
| `AIza…` | Google Gemini | 무료 한도 |
| `sk-or-…` | OpenRouter | `:free` 모델 무료 |
| `hf_…` | Hugging Face | 월 무료 크레딧 |
| `tgp_…` / DeepSeek / Mistral / SambaNova | | 접두어가 없으면 차례로 시험해 연결 |
| `tvly-…` / `BSA…` | Tavily / Brave 검색 | 선택. 없으면 무료 검색(DuckDuckGo → Bing) |

- **자동 선택**: 질문 종류(일반·코딩·추론·빠른 답)마다 연결된 회사들 중 가장 맞는 모델을 고릅니다.
- **자동 교체**: 한도(429)·오류·연결 실패가 나면 바로 다음 후보로 바꾸고, 막힌 곳은 잠시 뒤로 미룹니다.
- 특정 회사·모델을 고정하거나, Ollama(내 PC 대형 모델)·내 기기 AI(오프라인)도 쓸 수 있습니다.

> **학습에 대해**: NVIDIA 등 무료 API는 이미 학습된 모델을 빌려 쓰는 추론 전용이라 모델 자체를 다시 학습시킬 수 없습니다.
> 누리는 **스킬**(분야별 일하는 방식) · **기억**(나에 대한 정보) · **내 지식**(올린 문서) · **맞춤 지침**을 매번 참고해 나에게 맞춰집니다.
> 모델 미세조정은 GPU와 별도 환경(NVIDIA NeMo, Unsloth 등)이 필요합니다.

## 채팅 모드

그냥 말하면 질문에 맞는 **스킬**이 켜지고, 누리가 필요한 도구를 스스로 골라 씁니다.

| 분야 | 이렇게 말하면 | 도구 |
|---|---|---|
| 코인 현물 | "비트코인 분석해줘" | 업비트·바이낸스 시세, 지표, 퀀트 점수, 실시간 차트 패널 |
| 코인 선물 | "바이낸스 선물 BTC 롱숏 어때?" | 펀딩비·미결제약정·롱숏비율 |
| 국내·해외 주식, 지수 | "엔비디아 일봉 분석", "삼성전자", "나스닥" | 야후 파이낸스 차트 |
| 해외선물·원자재·환율 | "WTI 원유 선물", "금", "달러/원" | 야후 파이낸스 (CL=F, GC=F, ES=F, KRW=X …) |
| 경제 발표 | "이번 주 경제 발표 일정" | CPI·FOMC·고용 등 일정·예상치(한국시간) |
| 전략 | "RSI 전략 백테스트", "모의 매수" | 백테스트, 가상 계좌 |
| 건축 설계 | "대지 60평에 3층 주택 설계" | 3D·평면·인테리어, 건폐율·용적률 |
| CAD·Revit·SketchUp·Lumion | 패널의 내보내기 | DXF(AutoCAD) · IFC(Revit) · DAE/OBJ(SketchUp·Lumion·Twinmotion) |
| 렌더링 | "해 질 녘 외관 투시도로 렌더링" | NVIDIA 무료 이미지 AI (FLUX 등) |
| 견적서 | "250㎡ 철근콘크리트 주택 견적서" | 공종별 개략 공사비, 인쇄·PDF 견적서 |
| 토지·재개발 | "장위동 ○○ 재개발 가능성" | 용도지역 상한, 정비사업 판단요소·관련 법, 최신 자료 검색 |
| 부동산 | "마포구 아파트 경매 물건", "실거래가" | 인터넷 조사 + 법원경매·실거래가 공식 사이트 안내 |
| 인터넷 리서치 | "최신 ○○ 뉴스 정리해줘" | 검색 → 페이지 읽기 → 출처 번호 달아 정리 |
| 코딩·웹앱 | "할 일 관리 웹앱 만들어줘" | 결과물(웹페이지·코드·문서)을 패널에 표시·저장 |
| 기억 | "기억해줘: 나는 …" | 이후 모든 대화에서 참고 |

## 진행 상황 · 템플릿 · 스킬

- **진행 상황**(오른쪽 위 맥박 모양 아이콘, 넓은 화면에선 자동으로 열림): 지금 무엇을 하는지, 어느 AI가 답하는지, AI 교체, 켜진 스킬,
  도구 단계별 소요 시간, 할 일, 결과물, 출처를 실시간으로 보여 줍니다. 답변 아래 **과정** 버튼으로도 열 수 있습니다.
- **템플릿**: 투자·시장 / 건축·부동산 / 리서치·글쓰기 / 코딩 / 코드 모드 템플릿. [대괄호]만 바꿔 보내면 됩니다.
- **스킬**: 기본 스킬 7개(시장 분석가·거시경제·퀀트 전략·건축 설계·견적·부동산·토지·법규·인터넷 리서치·코딩)를 켜고 끌 수 있고,
  나만의 스킬(이름·켜지는 단어·지침)을 만들어 일하는 방식을 가르칠 수 있습니다.

## 모델 (설정 → 모델)

- **클라우드 모델 전체**: NVIDIA(build.nvidia.com)·Hugging Face·Groq·Gemini 등에 키를 넣으면 그 회사의 모델 목록 전체가 들어오고, 종류(대화·코딩·추론·이미지 이해·이미지 생성·임베딩·음성·안전 필터)별로 보고 고정할 수 있습니다. 평소에는 GH Nano가 질문마다 알맞은 모델을 고릅니다.
- **이미지 이해**: 사진·도면·차트 캡처를 첨부하거나 붙여넣으면 이미지를 볼 수 있는 모델(예: Llama 3.2 90B Vision, Llama 4)로 자동 전환합니다.
- **Hugging Face GGUF 모델**: 어떤 GGUF 모델이든 검색해서 Ollama 없이 앱 안에서 내려받아 실행합니다(분할 파일 지원, 4GB 그래픽카드에는 1~4B Q4 권장).
- **내가 만든 모델**: 학습한 모델을 앱 저장소(OPFS)에 보관하고 다음 실행 때 자동으로 켭니다.

## NVIDIA 공식 스킬 388개 (설정 → 스킬)

[NVIDIA/skills](https://github.com/NVIDIA/skills) 저장소의 **모든 파일 5,470개**(스킬 388개의 지침·참고문서·스크립트·이미지·서명 파일 + plugins·components.d·docs 등 저장소 나머지)를 압축해 `skills/nvidia/`에 내장했습니다. 빌드할 때 원본과 바이트 단위로 대조합니다(Apache-2.0 / CC-BY-4.0).
- GH Nano가 필요할 때 `nv_skill_search` → `nv_skill_read`로 찾아 읽고 그 절차를 따릅니다. 젯슨·cuOpt·옴니버스처럼 제품 이름을 말하면 맞는 스킬이 자동으로 켜집니다.
- **작업 폴더에 전체 설치**: 스킬은 `.claude/skills/<이름>/`(`npx skills add NVIDIA/skills`와 같은 위치), 저장소 나머지는 `.claude/nvidia-skills-repo/`에 원본 그대로 설치해 Claude Code·Codex·코드 모드에서 스크립트를 실행할 수 있습니다.
- 갱신: `python3 build_nvskills.py <NVIDIA/skills 클론> nuri-ai/skills/nvidia`

## 학습 · 내 모델 만들기 (설정 → 학습 · 내 모델)

NVIDIA 스킬(`data-designer`, `tao-finetune-huggingface-model`)과 같은 방식으로 작은 오픈모델을 직접 미세조정(LoRA)합니다.

1. **데이터 모으기**: 답변 아래 👍로 좋은 답을 표시 → 대화(도구 사용 과정 포함)를 학습 예시로 만듭니다. 👎 받은 답은 뺍니다.
2. **합성 데이터**: 주제·질문자·난이도·말투를 무작위로 섞어 큰 AI(선생)가 질문과 모범답안을 만들고, AI 채점으로 4점 이상만 남깁니다.
3. **학습**: `nuri-train.jsonl` + Colab 노트북(무료 T4 GPU, Unsloth 4비트 QLoRA) 또는 RTX 3050용 로컬 스크립트를 내려받아 실행 → `.gguf` 결과물.
4. **내 모델 등록**: `.gguf`를 Ollama에 한 번에 등록(그래픽카드 사용) 또는 내 기기 AI(2GB 이하)로 바로 실행.

| 바탕 모델 | 크기(Q4) | 라이선스 | RTX 3050 노트북 |
|---|---|---|---|
| Qwen3.5 2B (추천) | 약 1.3GB | Apache-2.0 | 실행 빠름, 로컬 학습 가능 |
| Qwen3.5 0.8B | 약 0.6GB | Apache-2.0 | 로컬 학습 가장 쉬움 |
| Qwen3.5 4B | 약 2.7GB | Apache-2.0 | Colab 학습, Ollama로 실행 |
| Gemma 4 E2B | 약 3GB | Gemma 약관 | Colab 학습 |
| EXAONE 4.0 1.2B | 약 0.8GB | 비상업 | 한국어 강함, 로컬 학습 가능 |

외부 스킬: 설정 → 스킬에서 NVIDIA 스킬 이름(예: `portfolio-optimization`)이나 GitHub 주소, `SKILL.md` 파일로 가져올 수 있습니다.

## 코드 모드 (exe 전용)

내 컴퓨터의 폴더를 열면 누리가 파일을 살펴보고, 고치고, 명령을 실행합니다.
파일을 바꾸거나 명령을 실행하기 전에 바뀌는 내용(diff)을 보여 주고 허락을 구합니다.
권한: 매번 묻기 / 편집 자동 허용 / 모두 자동 허용. 작업 폴더 밖은 접근하지 않습니다.

## 구조

- `index.html` 화면 틀과 스타일, `app.js` 화면 동작(진행 상황 패널, 설정, 템플릿·스킬·기억), `templates.js` 템플릿
- `engine.js` 저장소·내 기기 AI·여러 AI 회사 자동 선택/교체·인터넷 검색과 페이지 읽기·문서 검색·마크다운
- `agent.js` 도구 호출 규약(`<tool name="…">{…}</tool>`), 도구 모음, 스킬, 반복 실행
- `trade.js` 시세(업비트·바이낸스 현물/선물·야후)·지표·퀀트 점수·백테스트·트레이딩 룸
- `../launcher/` exe: 앱 내장, 외부 API 중계, 웹 가져오기(공용 인터넷 주소만), 코드 모드 파일·명령 처리

## 한계

- 지능은 연결한 모델에 달려 있습니다. 소형 모델은 도구 사용과 코딩을 잘 못합니다.
- 부동산 매물·법원경매는 무료 공개 API가 없어 인터넷 검색으로 조사하고 공식 사이트 링크를 안내합니다(실시간 매물 DB 아님).
- 견적서는 면적·용도·등급 기반 개략 견적입니다. 실제 금액은 도면·물량·현장 조건에 따라 다릅니다.
- 토지 규제·재개발 판단은 일반 정보이며 토지이음·지자체·전문가 확인이 필요합니다.
- 루미온 직접 연동은 없고, DAE/OBJ 파일을 루미온에서 가져오거나 AI 렌더링을 씁니다.
- 투자 분석은 과거 데이터 기반이며 미래 가격을 보장하지 않습니다. 실제 주문 기능은 없습니다.
