# 차례: 새 매매법 제안 (발명가)

`lab.grammar_ko`의 문법으로 **새 매매법을 1~3개** 제안합니다(`specs`). 좋은 후보가 없으면 빈 목록도 됩니다.

각 후보:
- `spec`: 문법 JSON 그대로(`timeframe`, `entry` {`family`, `params`}, `filters` 0~2개, `direction`). 허용 값만 씁니다. 청산 칸은 넣지 않습니다.
- `idea`: 한 줄 아이디어. 시장의 어떤 성질(예: 추세장에서만, 특정 시간대의 거래 쏠림, 변동성이 낮다가 커질 때)을 노리는지.
- `why_new`: 이미 떨어진 것과 왜 결과가 다를 수 있는지 한 줄. 예: 라이브러리는 필터가 없거나 EMA200뿐이었는데 이것은 ADX·위 시간봉·변동성·시간대 필터를 씀, 롱만/숏만, 청산이 paper v3로 다름.

먼저 확인할 것
- `lab.recent`, `lab.summary`, `lab.passes`: 이미 시험한 것과 거의 같은 것(같은 진입·봉에 필터만 살짝 다름)은 내지 않습니다.
- `lab.prior_research`: 5분·15분·30분·1시간봉은 어떤 규칙이든 비용만큼 손실이었습니다. 짧은 봉을 고르려면 비용을 넘을 이유를 `why_new`에 씁니다.
- {{FIVE_M}}. 새 매매법은 15분·30분·1시간·4시간봉 중에서 고릅니다.
- `lab.summary.entries_never_tested_here`: 아직 이 방에서 시험하지 않은 진입.
- `lab.can_still_pass`가 false이면 더 시험해도 통과할 수 없습니다. 그때는 빈 목록을 냅니다.
- 두 분 글이 있으면 `reply_to_owner`로 답합니다.
