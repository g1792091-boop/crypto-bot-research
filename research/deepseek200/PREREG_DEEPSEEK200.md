합성 자료 자체 시험에는 전체 규모(코인 6개 × 봉 4개 × 5.7년 분량)로 돌려 본 실행도 있습니다. 코드가 설정 342개를 끝까지 계산하고 관문을 판정하는지만 본 것이고, 결과에는 의미가 없습니다(우위를 심은 합성 자료에서는 관문이 통과를 내는 것도 확인했습니다).

연구일 뿐입니다. 지금 돌고 있는 30일 실험(paper v3, 2026-10-05 10:46 KST 재시작, 규칙 30일 동결)의 규칙, 계좌, 주문, 파일은 아무것도 건드리지 않습니다. 이 연구는 `research/deepseek200/` 안에서만 읽기 전용으로 돌아갑니다.

## 4. 공통 약속 (모든 정의에 적용)
**봉과 신호 시점**
- 모든 시각은 UTC입니다. 봉의 시각 = 시작 시각. 봉 `t`는 `시작 + 봉 길이`에 **닫힌** 봉입니다. 신호는 봉 `t`의 종가 시점에 알려지는 값만 씁니다(`t`보다 뒤 봉은 어떤 계산에도 안 씁니다).
- "다음 봉 시가 진입" = 신호가 난 봉 `t`가 닫힌 뒤 **봉 `t+1`의 시가**로 시장가 진입(백테스트방의 잠긴 엔진, 슬리피지 포함). 신호는 `t`의 종가에서만 판단합니다.
- 롱·숏 모두 시험합니다(정의가 방향을 정함). **같은 봉에서 롱과 숏이 동시에 나면 둘 다 버립니다.**
- 한 (설정, 코인)당 포지션은 1개: 이미 포지션이 있으면 그 사이의 신호는 무시(엔진 규칙). 보유 중 청산된 봉에서 난 신호는 허용(다음 봉 시가).
- ATR = `fg.atr(df, 14)` (와일더 RMA, 엔진과 같은 값). 이 문서의 "ATR"은 모두 이것이고, 신호 봉 `t`의 값입니다.
- 지표 워밍업: 앞 연구와 같이 각 코인 시리즈의 처음 `max(300봉, 30일)`은 신호에 안 씁니다(`lib.warmup_bars`). EMA 등 재귀 지표는 시리즈 시작부터 계산합니다.
- 봉 수로 정한 값(48봉, 20봉 등)은 **봉 길이와 상관없이 같은 봉 수**입니다(15분 20봉 = 5시간, 4시간 20봉 = 80시간). 봉 길이별로 따로 맞추지 않았습니다.

**스윙(피벗)**
- 스윙 고점: 봉 `p`의 고가가 **앞 3봉과 뒤 3봉의 고가보다 모두 엄격히 큼**(같으면 아님). 스윙 저점은 반대(저가가 모두 엄격히 작음).
- **확인 지연 3봉**: 스윙 `p`는 봉 `p+3`이 닫힌 뒤에야 알려집니다. 신호 판단에 쓰는 시점은 `p+3` 이후뿐입니다. "마지막 확인된 스윙 고점/저점"은 봉 `t` 시점에 확인이 끝난 것 중 가장 최근 것입니다. 수준(레벨)은 스윙 봉의 고가(저점은 저가)입니다.

**구조 상태 (F3·F11·F12·F13이 같이 씀)**
- 레벨 돌파 = 봉 종가가 마지막 확인된 스윙 고점 레벨보다 **위**(저점은 아래)에서 닫힘. 한 레벨은 한 번만 돌파로 셉니다(새 스윙이 확인되면 새 레벨).
- 구조 상태 `s` ∈ {+1, −1, 0(처음)}: 위 돌파가 나면 +1, 아래 돌파가 나면 −1. 상태 전 `s`와 돌파 방향으로 구분:
  - **BOS(구조 이어짐)**: 위 돌파인데 직전 상태가 +1, 또는 아래 돌파인데 직전 상태가 −1.
  - **MSS(구조 전환)**: 위 돌파인데 직전 상태가 −1, 또는 아래 돌파인데 직전 상태가 +1.
  - 직전 상태가 0이면(시리즈 처음 돌파) 이벤트로 세지 않고 상태만 정합니다.
  - 위 돌파와 아래 돌파가 같은 봉에서 모두 성립하면(레벨이 뒤집힌 드문 경우) 둘 다 무시합니다.

**구간(존) 되돌림 진입 (F3·F8·F9·F10·F16이 같이 씀)**
- 존은 `(생성 봉 b, 가격 하한 lo, 상한 hi, 방향, 무효선)`입니다. 생성 봉 `b`의 종가에 알려집니다. 유효기간 = `b+1 … b+50봉`(**50봉 고정**).
- 롱 존: 유효기간 안에서 **처음으로 `저가 ≤ hi`가 되는 봉 `s`**가 "첫 접촉"입니다. 그 봉이 정의의 **확인 조건**을 만족하면 그 봉 종가에서 롱 신호, 만족하지 않으면 존은 소멸(신호 없음). 예외는 F3_BOS_ZONE 하나뿐이고 그 정의에 따로 적었습니다. 숏 존은 `고가 ≥ lo`가 첫 접촉이고 확인 조건은 대칭.
- **무효선**: 롱 존은 첫 접촉 전에 `고가 > 무효선`인 봉이 있으면 소멸(무효선이 없는 존은 해당 없음). 같은 봉에서 무효선과 첫 접촉이 같이 일어나면 소멸로 봅니다(봉 안의 순서를 알 수 없으므로 보수적).
- 한 존은 신호를 한 번만 냅니다.

**ET 세션 시각 (F15)**
- ET = 미국 동부시간. **고정 변환 규칙**: 3월 둘째 일요일 07:00 UTC부터 11월 첫째 일요일 06:00 UTC 전까지는 EDT = UTC−4, 나머지는 EST = UTC−5(2007년 이후 미국 규칙, 시험 기간 2020~2026 모두 같은 규칙). 코드는 이 규칙을 직접 구현하고, 테스트가 IANA 시간대(America/New_York)와 시험 기간 전체에서 일치하는지 확인합니다.
- 세션 판정은 **ET 벽시계 시각**(UTC + 위 오프셋)으로 합니다. 예: 09:30 ET = 여름 13:30 UTC, 겨울 14:30 UTC. 02:00 ET = 여름 06:00 UTC / 겨울 07:00 UTC. 하루는 ET 날짜(자정 00:00 ET부터)입니다.
- 서머타임이 바뀌는 날(1년에 2번)의 봉은 벽시계 그대로 판정합니다(봄: 02:xx 봉이 없음, 가을: 01:xx 봉이 두 번 나옴, 둘 다 시간순으로 처리). 보정하지 않습니다. 범위(레인지)를 만드는 구간에 봉이 하나라도 빠졌거나 개수가 안 맞으면 **그 날은 신호를 내지 않습니다.**
- 세션 정의는 4시간봉에서 쓸 수 없습니다(4시간봉은 UTC 0·4·8…시에 정렬되어 ET 정시와 어긋나고 서머타임에 따라 달라짐). 그래서 **ET 기준 세션 정의 5개(F15_ASIA_BRK, F15_ASIA_SWEEP, F15_LON_BRK, F15_OPEN0930, F15_OPEN0000)는 15분·30분·1시간봉에서만** 시험합니다. 이건 정의상 제외이지 선택이 아닙니다. **UTC 날짜 기준 정의 2개(F11_PO3, F15_ORB)는 4개 봉 모두**에서 시험합니다.
- **UTC 날짜 기준 정의:** 하루 = 00:00 ~ 24:00 UTC(서머타임 없음). 범위를 만드는 봉이 예정된 시각대로 모두 있어야 하고(봉 하나라도 빠졌으면 그 날은 신호 없음), 범위는 그 봉들의 최고가·최저가입니다.

## 5. 정의 44개 (계열별)
기호: `C`=종가, `O`=시가, `H`=고가, `L`=저가, `V`=거래량, `[t]`=신호 봉, `[t-1]`=그 앞 봉. 롱을 적고 숏은 위·아래를 뒤집은 대칭입니다(별도 설명이 없으면).

### F1 다이버전스 (3개) — 목록 2, 15, 23, 133
**정의:** 확인된 스윙 고점 두 개 `a < b`(연속, 사이에 다른 확인된 스윙 고점 없음, `b−a ≤ 60`봉)에서 가격 `H[b] > H[a]`인데 지표 `I[b] < I[a]` → **숏**, 신호 봉 = `b+3`(확인 시점). 스윙 저점은 `L[b] < L[a]` & `I[b] > I[a]` → **롱**. 지표값은 스윙 봉 자체의 값. 지표 값이 비면 신호 없음.

|---|---|
| F1_RSI_DIV | RSI(14) (`pine_rsi`) |

### F2 디마크 피벗 (1개) — 목록 18
**F2_DEMARK:** 전날(UTC 달력 날짜, 그 날의 봉으로 만든 O=첫 시가, H, L, C=마지막 종가)로 `X` = (C<O이면 `H+2L+C`, C>O이면 `2H+L+C`, C=O이면 `H+L+2C`). `S1 = X/2 − H`, `R1 = X/2 − L`. 오늘 모든 봉에 어제 값을 씀(어제 봉이 없으면 신호 없음).
- 롱: `L[t] ≤ S1` 그리고 `C[t] > S1` (지지선 닿고 종가는 위로 회복). 숏: `H[t] ≥ R1` 그리고 `C[t] < R1`.

### F3 구조 돌파·공급수요 (3개) — 목록 24, 34, 105, 106, 107, 108, 112
- **F3_BOS** (24, 34, 106): BOS 이벤트 방향으로 진입. 위 BOS → 롱, 아래 BOS → 숏. 신호 봉 = 돌파 봉.
- **F3_BOS_ZONE** (105, 107, 108): 위 돌파(BOS 또는 MSS, 즉 상태 0이 아닌 모든 구조 돌파) 봉 `b`에서 **수요 존** 생성: 돌파 시점의 마지막 확인된 스윙 저점 봉 `k`의 `[L[k], H[k]]`(`lo=L[k]`, `hi=H[k]`). **이 정의만 "기다림" 방식**(반전 캔들을 기다려야 하므로 첫 접촉 규칙을 쓰지 않음): 유효기간 `b+1 … b+50` 안에서 봉마다 확인하되, **종가가 `lo` 아래로 닫히면 존 소멸**, 그 전에 처음으로 `L[s] ≤ hi`(존에 닿음) **그리고** 확인 조건을 만족하는 봉 `s`에서 롱 신호. 확인 조건: `C[s] > O[s]` 그리고 `C[s] > H[s−1]`(반전 캔들) 그리고 `C[s] > EMA(200)[s]`(`pine_ema`; 200봉 전에는 값이 없어 신호 없음) 그리고 `C[s] ≥ lo`. 숏은 아래 돌파 → 공급 존(마지막 확인된 스윙 고점 봉의 `[L, H]`), `C[s] > hi`이면 소멸, `H[s] ≥ lo` 그리고 `C[s] < O[s]`, `C[s] < L[s−1]`, `C[s] < EMA200[s]`, `C[s] ≤ hi`.
- **F3_HHHL** (112): 스윙 저점이 확인되는 봉 `t`에서, 새 저점 레벨이 직전 확인된 저점 레벨보다 높고(HL) 마지막 두 확인된 고점 레벨도 상승(HH)이면 롱. 스윙 고점이 확인되는 봉 `t`에서 새 고점 < 직전 고점(LH)이고 마지막 두 저점 레벨도 하락(LL)이면 숏.

### F4 EMA 눌림·정렬 (3개) — 목록 30, 45, 49, 67, 129, 130
- **F4_PULL** (45, 129): 롱: `[t-1]`에서 EMA9 > EMA50 > EMA200(정렬), `[t]`에서 `L[t] ≤ EMA50[t]` 그리고 `C[t] > EMA50[t]`(눌렸다가 같은 봉에서 복귀). 숏은 EMA9 < EMA50 < EMA200, `H[t] ≥ EMA50[t]`, `C[t] < EMA50[t]`.
- **F4_PULL_RSI** (30): 롱: `EMA20[t-1] > EMA50[t-1]`, `C[t] > EMA50[t]`, RSI(14)가 40을 아래→위로 교차(`RSI[t-1] ≤ 40 < RSI[t]`). 숏: `EMA20 < EMA50`, `C < EMA50`, RSI가 60을 위→아래로 교차(`RSI[t-1] ≥ 60 > RSI[t]`).
- **F4_FAN** (67, 130): EMA 8·13·21·34·55 (피보나치 리본). 롱 = `EMA8>EMA13>EMA21>EMA34>EMA55`가 **처음 성립하는 봉**(직전 봉은 불성립). 숏은 반대 순서.

### F5 박스권 (3개) — 목록 32, 58, 180, 181, 182
박스: 직전 48봉(`t−48 … t−1`)의 최고가 `hi`와 최저가 `lo`. `폭 = hi − lo`. **박스 유효** = `ADX(14)[t] < 20`(`fg.dmi_adx(14,14)`) 그리고 `폭 ≥ 3×ATR`. `위치 pos = (C[t] − lo)/폭`.
- **F5_BOX** (32, 58): 롱: 박스 유효, `0 ≤ pos ≤ 0.15`, `C[t] > O[t]`. 숏: 박스 유효, `0.85 ≤ pos ≤ 1`, `C[t] < O[t]`. (`pos`가 0~1 밖 = 박스 이탈 → 신호 없음.)
- **F5_BOX_RSI** (181, 182): 롱: 박스 유효, `0 ≤ pos ≤ 0.15`, `RSI(14)[t] < 30` (양봉 조건 없음). 숏: `0.85 ≤ pos ≤ 1`, `RSI(14)[t] > 70`.

### F6 VWAP (2개) — 목록 51, 52, 53
VWAP = **UTC 날짜별 앵커**(00:00 UTC에 리셋). `tp = (H+L+C)/3`, VWAP[t] = 그날 처음 봉부터 `t`까지 `Σ(tp×V)/ΣV`(`t` 봉 포함, 닫힌 봉). 그날 `ΣV = 0`이면 신호 없음.
- **F6_VWAP_CROSS** (51, 52): 롱: `C[t-1] ≤ VWAP[t-1]` 그리고 `C[t] > VWAP[t]`, 단 `t-1`과 `t`가 같은 UTC 날짜일 때만(날짜 첫 봉에서는 신호 없음). 숏은 반대.
- **F6_VWAP_FAIL** (53, 이탈 후 복귀 실패): 같은 UTC 날짜 안에서 봉 `k`에 종가가 VWAP 위→아래로 이탈(`C[k-1] ≥ VWAP[k-1]`, `C[k] < VWAP[k]`). `k` 다음 10봉(`k+1 … k+10`, 같은 날짜) 중 **처음으로** `H[t] ≥ VWAP[t]` 이고 `C[t] < VWAP[t]` 이고 `C[t] < O[t]`인 봉 `t`(복귀 시도 후 종가는 다시 아래)에서 **숏**. 그 사이에 종가가 VWAP 위로 올라온 봉이 있으면 그 이탈은 폐기. 롱은 대칭(아래→위 이탈 후 재시험 실패).

### F7 Range Filter 3중 일치 (2개) — 목록 62, 63, 65
- **Range Filter**(DonovanWall 원본, 종가 기준, 기본값 100/3.0): `avr = EMA(|C − C[-1]|, 100)`, `rng = 3.0 × EMA(avr, 199)`(`ewm(span, adjust=False)`). `filt[0]=C[0]`; 이후 `x=C[t]`, `f=filt[t-1]`: `x−rng > f`이면 `filt = x−rng`, `x+rng < f`이면 `filt = x+rng`, 아니면 `filt = f`. 방향 `dir`: `filt > filt[-1]`이면 +1, `<`이면 −1, 같으면 직전 `dir` 유지.
- **하이킨아시 색**: `HAc = (O+H+L+C)/4`, `HAo[0] = (O[0]+C[0])/2`, `HAo[t] = (HAo[t-1]+HAc[t-1])/2`. 양(상승) = `HAc > HAo`. 상위 봉의 하이킨아시도 같은 식으로 상위 봉 시리즈에서 계산하고, `t`의 종가 시각 이전에 닫힌 마지막 상위 봉의 색을 씀(상위 봉은 F5와 같은 대응).
- **F7_RF_TRIPLE** (62, 65): `dir=+1` 그리고 하이킨아시 양 그리고 상위 하이킨아시 양, 이 세 가지가 **처음 모두 성립하는 봉**(직전 봉은 불성립)에서 롱. 숏은 세 가지 모두 음.
- **F7_RF_ONLY** (63): `dir`이 −1에서 +1로 바뀌는 봉에서 롱, +1에서 −1로 바뀌면 숏(3중 일치 없이 Range Filter만).

### F8 Virgin Wick POI (1개) — 목록 72
- **F8_VWICK:** 큰 몸통 캔들 봉 `k`: `|C−O| ≥ 0.7×(H−L)` 그리고 `|C−O| ≥ 1.3×ATR[k]`. **양봉**이면 롱 존: `lo=hi=L[k]`(꼬리 끝, 대개 아랫꼬리), 생성 봉 `k`. 첫 접촉(`L[s] ≤ L[k]`) 봉의 확인: `C[s] > L[k]`(꼬리 끝을 종가로 지킴). **음봉**이면 숏 존 `lo=hi=H[k]`, 첫 접촉 `H[s] ≥ H[k]`, 확인 `C[s] < H[k]`. "처녀(virgin)" = 첫 접촉 전에 한 번도 닿지 않음(존 규칙이 그대로 보장).

### F9 FVG·오더 블록 (4개) — 목록 74, 85, 86, 87, 88, 89, 96, 97, 98
**FVG(공정가치 갭):** 봉 `t`가 닫힐 때, 상승 FVG = `L[t] > H[t-2]`, 갭 `[H[t-2], L[t]]`, 크기 `L[t]−H[t-2] ≥ 0.5×ATR[t]`(작은 갭 제외, 0.5 고정). 하락 FVG = `H[t] < L[t-2]`, 갭 `[H[t], L[t-2]]`, 크기 `≥ 0.5×ATR[t]`. 생성 봉 `b=t`.
- **F9_FVG** (87): 상승 FVG → 롱 존(`lo=H[b-2]`, `hi=L[b]`, 무효선 없음). 첫 접촉 봉 `s`(`L[s] ≤ hi`)의 확인: `C[s] ≥ (lo+hi)/2`(존 중간 이상으로 종가). 하락 FVG → 숏 존, 첫 접촉 `H[s] ≥ lo`, 확인 `C[s] ≤ (lo+hi)/2`.
- **F9_IFVG** (74, 88): 상승 FVG(`lo,hi`, 생성 `b`)가 **반전**되는 봉 `v` = `b+1 … b+50` 중 처음으로 `C[v] < lo`인 봉. 반전 뒤 존은 **숏 존**(같은 `lo, hi`, 생성 봉 `v`, 유효 `v+1 … v+50`). 첫 접촉 `H[s] ≥ lo`, 확인 `C[s] ≤ (lo+hi)/2`. 하락 FVG가 `C[v] > hi`로 반전되면 **롱 존**(첫 접촉 `L[s] ≤ hi`, 확인 `C[s] ≥ 중간`).
- **F9_OB** (96): 상승 오더 블록: 봉 `k`가 음봉(`C<O`), 봉 `k+1`이 `C[k+1] > H[k]`, 봉 `k+2`가 `L[k+2] > H[k]`(갭을 남긴 변위). 생성 봉 `b=k+2`, 롱 존 `lo=L[k]`, `hi=H[k]`, 무효선 없음. 첫 접촉 `L[s] ≤ hi`, 확인 `C[s] ≥ (lo+hi)/2`. 하락 OB: 봉 `k` 양봉, `C[k+1] < L[k]`, `H[k+2] < L[k]` → 숏 존 `[L[k], H[k]]`, 첫 접촉 `H[s] ≥ lo`, 확인 `C[s] ≤ 중간`.
- **F9_BREAKER** (86): 위 OB 존이 **뚫리는** 봉 `v` = `b+1 … b+50` 중 처음 `C[v] < lo`(상승 OB의 저가 아래 종가)이면 그 존은 **숏 존**으로 바뀜(같은 `lo,hi`, 생성 `v`, 유효 `v+1 … v+50`), 첫 접촉 `H[s] ≥ lo`, 확인 `C[s] ≤ 중간`. 하락 OB가 `C[v] > hi`로 뚫리면 롱 존.

### F16 피보나치 되돌림 (4개) — 목록 39, 40, 134, 135, 136, 137
**임펄스 구간:** 스윙 고점 `H`(봉 `p`)가 봉 `c=p+3`에 확인될 때, 그 시점 마지막 확인된 스윙 저점 `L`(봉 `q`)과 짝을 지어 `H−L ≥ 3×ATR[c]` 그리고 `p−q ≤ 30봉`이면 **상승 임펄스**. 존: 생성 봉 `c`, 레벨 `R = H − f×(H−L)`(`lo=hi=R`), 무효선 `H`(첫 접촉 전에 `H[t] > H`이면 소멸). 첫 접촉 `L[s] ≤ R`의 확인: `C[s] > R`. **롱 신호.** 하락 임펄스(스윙 저점 확인 시 마지막 스윙 고점과 짝)는 `R = L + f×(H−L)`, 무효선 `L`, 첫 접촉 `H[s] ≥ R`, 확인 `C[s] < R`, **숏 신호.**

### F17 Z-score 평균회귀 (2개) — 목록 151, 152
`Z = (C − SMA20)/표준편차20`(모표준편차, ddof=0, 최근 20봉 종가).
- **F17_Z** (152): 롱: `Z[t] < −2` 그리고 `Z[t-1] ≥ −2`(처음 −2 아래로 내려온 봉). 숏: `Z[t] > +2` 그리고 `Z[t-1] ≤ +2`.
- **F17_Z_HL** (151): F17_Z에 **반감기 관문**을 더함. `x = ln(C)`. 최근 100개 쌍 `(x[t-j-1], x[t-j])`, `j=0…99`로 `x_t = a + φ·x_{t-1}` 최소제곱 회귀의 `φ`를 구함. **`φ ≤ 2^(−1/20) ≈ 0.9659`**(반감기 `−ln2/ln φ ≤ 20봉`; `φ ≤ 0`은 매우 빠른 회귀로 통과)일 때만 F17_Z 신호를 허용.

## 11. 판정 규칙 (미리 정함)
- **후보 = 1·2·3단계를 모두 통과하고, 전체 N에 대한 BH(q=10%, p12)도 통과한 설정.** 3단계까지만 통과하고 BH를 못 넘으면 "약한 후보(관찰용)"로만 적고 후보로 세지 않습니다.
- **20배 후보** = 후보 중 20배 조건도 통과한 것.
- 어떤 설정도 후보가 못 되면 **"이 목록의 새 계열에서 우위를 못 찾았다"**가 결론입니다. 정의를 바꾸거나 숫자를 조정하는 다음 시험은 하지 않습니다(하려면 새 사전 등록, N 증가).
- 후보가 있어도 결과를 해석할 때 지킬 것: 같은 계열의 정의·봉·청산은 서로 비슷한 신호를 내므로 독립 시험이 아닙니다(후보 하나는 사실상 계열 하나의 증거). 롱만 이기고 숏이 지는 식의 방향 편중, 한 코인에 몰린 이익, 한 해에 몰린 이익은 결과 표에서 따로 확인합니다.
