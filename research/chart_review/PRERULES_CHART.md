## 2. 규칙 (신호 봉이 닫힌 시점까지의 정보만)
ATR = ATR14. "방향 맞춤" = 롱은 그대로, 숏은 부호를 뒤집음.

| 특징 | 정의 |
|---|---|
| counter4 | 직전 4봉 동안 진입 반대 방향으로 움직인 크기 ÷ ATR (방향 맞춤: −side × (종가 − 4봉 전 종가) / ATR) |
| bigbody4 | 직전 4봉 중 가장 큰 캔들 몸통 ÷ ATR |
| range16 | 직전 16봉 고저 폭 ÷ ATR |

**문턱값 정하는 법:** 결과가 아니라 **차트 기록 코드와 맞도록** 정했습니다(60건의 코드 대 특징값, `rules.py calib`).
- counter4: FADE-SPIKE로 적은 거래의 중앙값 0.79, 아닌 거래 0.04 → 0.6
- bigbody4: 급등락으로 적은 거래 1.46, 아닌 거래 0.71 → 1.2
- range16: FLAT 2.77, 아닌 거래 3.57 → 2.8
- pos100: 추격 0.83, 아닌 거래 0.60 → 0.8
- trend100: WITH 5~6, 아닌 거래 0 근처 → 3
- srsi_k: 도지 OS 22.8, 아닌 거래 34.6 → 25
- 변동성은 처음 생각한 "ATR ÷ 평소 ATR"이 차트 코드와 맞지 않았습니다(0.95 대 0.98). 차트에서 본 "캔들이 작다"는 화면 범위 대비 크기라서 atr_rel로 바꿨고, 기록 비율(17~20%)에 맞춰 0.075(전체 거래의 약 20%)로 정했습니다.
  - 도지 매매법은 atr_rel도 코드와 잘 맞지 않았습니다(0.089 대 0.093). 그래도 세 매매법에 같은 정의를 씁니다.

## 3. 검사 (PREREG_CHART.md 6단계 그대로)
- 대상: 고르는 구간(2021-08 ~ 2024-06)의 그 매매법 전체 거래에서 차트로 본 60건을 뺀 것. V4.5 4,566 / V3.9 12,989 / 도지 3,024건(특징값이 비는 초기 구간 거래는 뺌).
- d = 조건 거래 평균 순손익 − 나머지 평균. 표준오차는 진입 날짜로 묶음. 양쪽 모두 100건 이상일 때만.
- 13개 규칙 전체에 Benjamini-Hochberg(q = 10%).
- 통과 조건 (모두):
  1. 보정 후 유의
  2. 방향이 맞음: (가)는 d < 0, (나)는 d > 0
  3. 조건·나머지가 각각 20건 이상인 코인 중 과반, 최소 4개에서 d가 같은 부호
  4. 앞 절반(2021-08~2022-12)·뒤 절반(2023-01~2024-06) 모두 같은 부호
- 무작위 진입(같은 엔진·청산·비용, 5세트)에 같은 규칙을 적용한 d를 나란히 보고합니다. 도지 매매법은 롱만 하므로 무작위도 롱만 씁니다.
