# 추세 사냥 "넓게" (사전 등록 초안, 아직 안 돌림)

규칙 원문은 `PREREG_HUNT_WIDE.md`(영어)입니다. v1(`README_KO.md`, 진입 3가지)은 그대로 따로 돌고, 이것은 그 옆에
붙는 두 번째 시험입니다. 규칙봇·후보 리그·실제 계좌는 건드리지 않습니다.

## 결론 먼저

1. **3개만 볼 이유가 없습니다.** 이미 코드로 만들어 둔 진입 신호를 **전부** 같은 "추세 사냥 기계"에 넣습니다.
   → **시스템 730개**.
2. 2021~2023 자료로 **상위 10개**만 고르고(매매법 하나당 최대 1개), 2024-01 ~ 2026-09에 **각각 딱 한 번** 시험합니다.
3. 운으로 좋아 보이는 것은 v1과 같은 방법으로 거르고, 10개를 같이 보니 기준을 **더 엄하게** 합니다.
4. **통과한 것만** 10/20 무렵 모의(paper) 봇으로, v1 옆에서 돌립니다. **실제 돈은 11월 중순 검토 전에는 안 씁니다.**

## 왜 3개가 730개가 되나

| 진입 신호 | 무엇 | 시스템 수 |
|---|---|---|
| 새 3개 | v1의 E1 돌파·E2 수축·E3 변동성 확장 | 3 × 봉 4 × 문지기 2 = 24 |
| 규칙봇 36개 | 지금 규칙봇의 36개, 기본 숫자 | 36 × 4 × 2 = 288 |
| 딥시크 44개 | 기본 숫자 (세션형 5개는 4시간봉 버전이 없음) | 342 |
| 관찰 후보 38개 | 후보 리그의 38개 숫자, 원래 봉에서만 | 38 × 2 = 76 |
| **합** | 봉 4가지 = 15분·30분·1시간·4시간, 문지기 = 추세장만 / 없음 | **730** |

(처음에 740으로 셌는데, 딥시크 세션형 5개는 4시간봉이 없어서 730입니다.)

## 그대로인 것과 바뀐 것

* **그대로 (기계):** 코인 30개, 신호 다음 5분봉에 진입, ATR 첫 손절, 불타기 최대 3번(전체 손실은 처음 한 번 몫까지),
  추적 손절로만 청산, 동시 6개, 열린 위험 합계 4%, 수수료·슬리피지·펀딩, 한 번에 거는 위험 0.5%.
* **각 매매법의 원래 익절·손절·레버리지는 안 씁니다.** "어디서 들어가나"만 빌려 오고, 나머지는 기계가 합니다.
* 15분·30분봉의 첫 손절은 1시간봉처럼 2 ATR. 신호가 여러 봉 동안 "켜져 있는" 매매법은 **켜지는 순간에 한 번만** 들어갑니다.
* 고르는 기준: 36개월에 72번 이상 진입, 월 평균 성장이 플러스, **비용 2배여도 플러스**, 파산 없음. 그중 점수(월 평균
  로그 성장) 상위 10개.
* 돌리기 전에 먼저 확인: 지금 6개 코인에서 규칙봇·딥시크 신호가 이전 풀그리드 연구와 **같은 봉에서** 나오는지 맞춰
  봅니다(신호만, 돈 계산 없음). 1% 넘게 다르면 고친 뒤에 고정합니다.

## 운은 어떻게 거르나

730개를 보면 그중 1등은 실력보다 운이 섞여 있습니다. 그래서:

1. **고르는 기간과 시험 기간을 나눕니다.** 시험 기간에는 고른 10개만 한 번씩 돌리고, 나머지는 돌리지 않습니다.
2. 같은 기계에 **아무 때나 들어간 것 100번**, **같은 때 방향만 동전으로 정한 것 100번**과 비교해서 둘 다 이겨야 합니다.
3. 10개를 한꺼번에 보니 "10개 중 하나쯤은 우연히 통과"하는 일을 막는 보정(BH 10%)을 합니다.
4. 비용 2배, 최대 낙폭 50% 미만, 파산 없음도 같이 통과해야 합니다.

솔직하게: 지금 6개 코인과 관찰 후보 38개는 이전 연구에서 결과를 이미 봤습니다. 그래서 **새 코인 24개만으로 낸 결과**를
옆에 꼭 같이 붙입니다. v1과 이것, 시험이 두 개라 둘 중 하나가 우연히 통과할 가능성도 하나일 때보다 큽니다(결과에 함께 적음).

## 30~50배 목표에 대해

위험 0.5%로는 한 달 30배가 사실상 나오지 않습니다(v1 설명과 같음). 그래서 **통과한 것에 한해** 위험을 2%·5%로 키우면
"2배·10배·30배가 된 달이 몇 %였는지, 가장 나쁜 달, 파산했는지"를 시험 기간 자료로 같이 보여 드립니다. 크게 걸수록 파산도
커집니다. 이것은 참고이고 통과 조건이 아니며, 2%·5% 모의 계좌는 결과를 보고 두 분이 정합니다.

| 날짜(KST) | 할 일 |

| 10/11 | 이 초안 |
| 10/12 ~ 10/15 | 30개 코인 자료 받기 마무리, 코드·시험 코드, 신호 일치 확인, 고정 |
| 10/15 ~ 10/18 | 고르기(730개) → 10개 고정 → 시험 한 번 → 결과 페이지(v1과 나란히). 오래 걸리면 큰 서버 |

| 11월 중순 | 검토. 3주 반 모의로는 "증명"은 못 하고, 규칙대로 움직였는지·시험 범위 안인지를 봅니다 |

실패하면 그대로 기록합니다. 시험 기간을 본 뒤 숫자를 고쳐 다시 돌리지 않습니다(고치면 새 연구, 앞으로의 자료로만 판정).
