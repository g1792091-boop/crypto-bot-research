# 2번 트랙: 승률 70% + 낙폭 한도 (사전 등록 초안, 아직 안 돌림)

규칙은 결과를 보기 전에 `PREREG_HIWR.md`(영어)에 고정합니다. 지금은 **초안**이고 코드도 아직 없습니다.
**물어본 것은 10/12 아침 답으로 모두 정했습니다** (아래 "정한 것"). 이제 코드 작성 → 검토 → 고정(sha256) → 서버
계산 순서로 갑니다. 1번 트랙(추세 사냥)과 **따로** 계산하고 결과는 **나란히** 보여 드립니다. 규칙봇·후보 리그·실제
계좌는 건드리지 않습니다.

## 두 분 말씀을 이렇게 계산합니다

| 말씀 | 이렇게 계산합니다 |
|---|---|
| 30배 9~12%, 40배 12~15%, 50배 15~18% | 한 번 매매의 **익절 목표**입니다. **수수료를 뺀 뒤** ROE입니다(10/12 답). 그래서 익절 가격에 비용을 더해 둡니다. 시장가 익절은 +0.14%, 지정가 익절은 +0.09%를 더합니다 (아래 표) |
| 낙폭 15분 15%, 30분 20%, 1시간 30%, 4시간 30% | 한 번 매매의 손실이 아니라 **계좌 전체**가 최고점에서 가장 많이 떨어진 비율입니다. 4시간 30%는 10/12에 확인해 주셨습니다 |
| 승률 70% 이상 | 수수료·슬리피지·펀딩을 **뺀 뒤** 이긴 매매의 비율입니다 |
| 주말장 제외 (4시간봉도) | 토요일 00:00 ~ 월요일 00:00 **UTC**(한국 시간 토 09:00 ~ 월 09:00)에 마감한 봉의 신호로는 들어가지 않습니다. 네 봉 모두 같습니다. 금요일에 들어간 포지션은 그대로 둡니다. 주말을 포함한 결과는 비교용으로만 옆에 적습니다 |
| 5년치 | 2021~2023년은 연습 기간이라 마음대로 봅니다. 2024-01~2026-09는 확인 기간이라 **딱 한 번**만 봅니다 |
| 보조지표 커스텀 값·진입 조건 | 매매법 80개(규칙봇 36 + 딥시크 44)의 숫자를 기본값의 1/3배~3배(9단계)로 모두 바꿔 봅니다. 진입 조건 규칙은 주말 제외 하나입니다 |

**익절 가격** (진입가에서 움직여야 하는 폭):

| 레버리지 | ROE (수수료 뺀 뒤) | 시장가 익절 | 지정가 익절 |
|---|---|---|---|
| 30배 | 9 / 10.5 / 12% | +0.44 / +0.49 / +0.54% | +0.39 / +0.44 / +0.49% |
| 40배 | 12 / 13.5 / 15% | +0.44 / +0.48 / +0.52% | +0.39 / +0.43 / +0.47% |
| 50배 | 15 / 16.5 / 18% | +0.44 / +0.47 / +0.50% | +0.39 / +0.42 / +0.45% |

* 세 레버리지 모두 **거의 같은 0.4~0.5% 움직임**입니다. 레버리지는 증거금 크기와 손절 둘 자리만 바꿉니다.
* 익절 한 번은 목표 ROE가 그대로 남습니다. 반대로 **1% 손절 한 번은 30배 약 −34%, 40배 약 −46%, 50배 약
  −57%**입니다.
* 수수료 전 ROE(바이낸스 화면 값, 가격 +0.30~0.40%)는 비교용으로만 옆에 적습니다.

| 코인 | 1번 트랙과 같은 30개입니다. 중간에 거래가 끝난 8개는 비슷한 알트(SAND·COMP)의 구간표를 빌려 씁니다 |

## 연습 기간(2021~2023)에서 고르는 기준

1. 150번 이상 매매, 승률 70% 이상, 평균 수익 플러스, 비용 2배여도 플러스
2. 바로 옆 설정(익절 한 단계, 손절 한 단계, 숫자 한 단계 위아래)도 같은 조건을 통과할 것. 운 좋은 한 점이 아니라
   넓은 "고원"이어야 합니다. 옆 설정의 매매가 손절 자리 부족으로만 줄었으면 50번 이상일 때 평균·비용 2배만 보고,
   50번 미만이면 없는 것으로 칩니다
3. 낙폭 한도에 맞춘 증거금 크기에서 계좌가 늘어날 것 (계좌 매매 100번 이상)
4. 같은 신호에서 방향만 동전으로 정한 것 200번 중 **95%보다** 나을 것
5. 칸(매매법 × 봉)마다 **최대 1개**만 고릅니다

## 확인 기간(2024-01~2026-09) 통과 기준

고른 것만, 딱 한 번 봅니다. 모두 만족해야 통과입니다.

1. 100번 이상 매매
2. 비용을 뺀 뒤 승률 70% 이상
3. 연습 기간에 정한 증거금 크기 그대로 낙폭이 한도 안
4. 평균 수익 플러스, 비용 2배여도 플러스
5. 같은 시각에 **방향만 동전으로 정한 것** 10만 번, **아무 때나 들어간 것** 10만 번 둘 다보다 뚜렷하게 나음
6. 고른 것 전체를 함께 보는 보정(BH, q = 0.10)을 통과

이 확인은 프로그램 전체 장부에 한 번으로 기록됩니다. 1번 트랙과 같은 기간을 쓰므로, 둘 중 하나라도 운으로 통과할
확률은 하나만 볼 때보다 큽니다. 결과에 그대로 적습니다.

## 솔직하게 (연습 기간 미리보기, 수수료 뺀 ROE, 지금 6개 코인)

10/12 답에 맞춰 연습 기간만 다시 계산했습니다 (규칙봇 36개 기본값, 손절 9개 모두).

* **승률 70%는 이 익절 방식이 거저 만들어 줍니다.** 0.4~0.5% 익절에 더 넓은 손절이면 **아무 데서나** 들어가도
  52~79%를 이깁니다. 하지만 본전이 되려면 승률이 **71~85%** 필요합니다.
* 모든 봉에서 들어가 보면 매매당 평균 약 −0.11%(지정가 익절) ~ −0.14%(시장가 익절)입니다. 딱 비용만큼 잃습니다.
* 위 고르는 기준 1번(150번, 승률 70%, 평균 플러스, 비용 2배 플러스)을 넘은 설정 수:

  | | 15분 | 30분 | 1시간 | 4시간 |
  |---|---|---|---|---|
  | **주말 제외 (규칙)** | **0** | **0** | **0** | **8개: 모두 S4_BB_BBP, 30배, 지정가 익절 +0.39~0.49%, 손절 ATR 1배·1%·1.25%** |
  | 주말 포함 (비교) | 0 | 0 | 10개 (40·50배) | 1개 (S4_BB_BBP) |
  | 동전 방향 (어느 쪽이든) | 0 | 0 | 0 | 0 |
  | 참고: 수수료 전 ROE, 주말 제외 | 0 | 0 | 0 | 3개 (S4_BB_BBP) |

* **그 8개도 고르는 기준 2번(고원)에서 모두 떨어집니다.** 바로 옆 손절(ATR 1.5배, 0.75%, 1.5%)이 비용 2배에서
  마이너스이기 때문입니다. 그래서 **기본값에서는 정식 규칙으로 고를 것이 하나도 없습니다** (수수료 전과 같음).
  고른다면 숫자를 바꾼 조합에서 나오는데, 그만큼 우연도 큽니다.
* 그 8개는 동전 비교(200번 중 95%보다 나음)는 넘었습니다.
* 넘은 것은 모두 **지정가 익절 덕분**입니다. 같은 ROE의 시장가 익절이면 8개 모두 비용 2배에서 마이너스입니다.
* **진입 신호가 조금은 돕습니다.** 같은 시각 동전 방향보다 승률이 4시간 약 2.4%p, 1시간 약 1.6%p, 30분 약 0.7%p,
  15분 약 0.3%p 높습니다. 본전이 되려면 아무 데서나 들어간 것보다 5~14%p가 더 필요합니다.
* **주말 제외는 연습 기간에 거의 차이가 없었습니다** (매매당 ±0.005%p 안팎). 두 분이 정한 규칙이라 그대로 지킵니다.
* **40배·50배는 더해 주는 것이 없습니다.** 50배는 청산가가 BTC도 1.6%밖에 떨어져 있지 않아 손절 둘 자리가 거의
  없습니다. 4시간에서 넘은 8개도 모두 30배입니다.
* **증거금 크기와 월 수익** (4시간 8개. 같은 기간에서 여러 개 중 고른 것이라 실제보다 좋아 보이고, 고원 조건은 못
  넘었습니다):

  | 설정 | 연습 기간 경로에 딱 맞춘 크기 | **등록 크기 (95%)** |
  |---|---|---|
  | 익절 +0.44%, 손절 ATR 1배 | 증거금 27%, 월 +4.1% | **22%, 월 +3.4% (36개월 약 3.4배)** |
  | 익절 +0.44%, 손절 1% | 20%, 월 +5.3% | **13%, 월 +3.4% (36개월 약 3.4배)** |
  | 8개 전체 | 16~27%, 월 +2.3~5.3% | **10~22%, 월 +1.8~3.4%** |

  딱 맞춘 크기는 섞어 만든 경로의 13~45%에서 낙폭 30%를 넘습니다. 그래서 95% 크기를 씁니다.
* **한 달에 5배~100배는 낙폭 15~30% 한도와 맞지 않습니다.** 예를 들어 15분봉 낙폭 15%에 맞춘 크기(30배 증거금 약
  9.5%)에서 ROE 9% 익절·1% 손절이면, 이기면 계좌 +0.86%, 지면 −3.25%입니다. 100% 이겨도 5배까지 약 190번 연속
  승리가 필요합니다.
* 이번 계산은 설정 약 1억 6천만 개를 뒤집습니다. 그래서 연습 기간에서 통과하는 것은 **우연으로라도 반드시**
  나옵니다. 풀그리드 때 고른 것들도 연습 기간에는 좋아 보였지만 확인 기간에서 유지되지 못했습니다.
* **결론은 수수료 전 ROE 때와 같습니다.** 가장 그럴듯한 결과는 15분·30분 통과 없음입니다. 통과가 있다면 4시간
  30배 지정가 익절, S4_BB_BBP 같은 종류일 가능성이 큽니다. 그때도 연습 기간 속도는 월 2~3.5%쯤입니다.

## 서버 (10/12 결정: 따로 돌림)

Vultr 월 요금 한도 때문에 64 vCPU 서버가 거절됐습니다. 그래서 32 vCPU 두 대를 동시에 쓰는 것도 거절될 가능성이
큽니다. **추세 사냥 서버가 끝나고 없어진 뒤에 새 서버로 따로 돌립니다.**

1. 2번 트랙 코드 작성 → 검토 → 고정. 그 전에는 아무것도 돌리지 않습니다.
2. 추세 사냥(hunt-compute)이 끝나면 결과를 저장하고 그 서버를 **Destroy**합니다.
3. 새 서버(CPU Optimized 32 vCPU, 도쿄)를 만들고 `SERVER_KO.md`의 **한 줄**을 붙여 넣습니다. 고정된 코드가 올라오면
   알아서 시작합니다(이미 올라와 있으면 바로 시작).
4. 약 8~9시간(약 $8~10) 뒤 결과를 저장하고 Destroy합니다. 확인 기간 계산은 나중에 1시간쯤 따로 합니다.

서버는 꺼 둬도 요금이 나가므로, 2번이 끝난 뒤에 만드시면 됩니다.
