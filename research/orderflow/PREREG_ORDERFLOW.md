# 주문 흐름 매매법 — 사전 등록 (데이터를 받기 전에 고정)

작성: 2026-09-30 (KST). 코드 `orderflow.py`와 함께, **주문 흐름 데이터를 받기 전에** 커밋합니다. 합성 데이터 자체 시험(`selftest`, 미래 정보 사용 여부 포함)만 돌렸습니다.

## 1. 왜 하는가
- 가격·거래량만 쓰는 매매법은 약 1,300개 조합에서 0개 통과였습니다(`research/search/RESULTS_SEARCH.md`).
- 가격 차트에 없는 정보(펀딩비, 미결제약정, 롱숏 비율, 테이커 매수·매도 비율, 프리미엄)로 방향을 맞힐 수 있는지 봅니다.
- 이 정보들은 "누가 레버리지로 한쪽에 몰렸는지"를 보여 줍니다. 짧은 시간(15분~몇 시간)에 크게 움직이는 원인이라 20~50배와 맞을 수 있습니다.

## 2. 데이터 (바이낸스 공개 자료, `data/orderflow/`)
| 자료 | 주기 | 쓰는 값 |
|---|---|---|
| fundingRate | 8시간 정산 | 정산된 펀딩비 (정산 시각부터 사용) |
| metrics | 5분 | 미결제약정 금액, 일반 계정 롱숏 비율, 상위 트레이더 롱숏 비율, 테이커 매수/매도 비율. **찍힌 시각 + 5분부터 사용** (공개 지연을 보수적으로 반영) |
| premiumIndexKlines | 1시간 | 프리미엄 지수 종가 (그 시간이 끝난 뒤 사용) |

모든 특징은 1시간 단위로 만들고, 그 시간이 끝난 뒤에만 씁니다. 차트 봉에는 봉이 닫힌 시점 이전에 끝난 마지막 시간의 값을 붙이고, 2시간보다 오래된 값은 쓰지 않습니다.

## 3. 매매법 7개 (롱/숏 모두)
기준 분포는 모두 **지난 값만**으로 만듭니다: 30일(720시간) 또는 펀딩 90일(270회).

| ID | 가설 | 규칙 |
|---|---|---|
| H1_FUNDING_FADE | 펀딩 극단 = 한쪽 쏠림 → 반대로 | 방금 정산된 펀딩이 90일 중 상위 5%이고 > 0.01% → 숏. 하위 5% → 롱 |
| H2A_OI_UP_CONT | 미결제약정 급증 + 가격 움직임 = 새 포지션 유입 → 따라가기 | 1시간 미결제약정 변화 z > 2 이고 1시간 수익률 \|z\| > 1 → 가격 방향으로 |
| H2B_OI_DOWN_FADE | 미결제약정 급감 + 가격 움직임 = 강제 청산·숏커버 → 되돌림 | 미결제약정 변화 z < −2 이고 \|수익률 z\| > 1 → 가격 반대 방향으로 |
| H3A_RETAIL_FADE | 일반 계정 쏠림 → 반대로 | 일반 계정 롱숏 비율이 30일 중 상위 5% → 숏, 하위 5% → 롱 |
| H3B_TOP_VS_RETAIL | 상위 트레이더와 일반 계정이 반대일 때 상위 트레이더 쪽으로 | (상위 트레이더 비율 순위 − 일반 계정 순위) ≥ 0.7 → 롱, ≤ −0.7 → 숏 |
| H4_TAKER_CONT | 공격적 매수·매도 쏠림 → 따라가기 | 1시간 평균 log(테이커 매수/매도) z > 2.5 → 롱, < −2.5 → 숏 |
| H5_PREMIUM_FADE | 선물 프리미엄 과열 → 반대로 | 프리미엄이 30일 중 상위 2% → 숏, 하위 2% → 롱 |

신호는 조건이 켜지는(또는 방향이 바뀌는) 첫 봉에서만 냅니다.

## 4. 봉, 청산, 엔진, 판정
- 봉: 15분, 1시간. 가격, 엔진, 비용, 청산 5종(손절 1·익절 2, 손절 1.5·익절 3, 손절 1·익절 3, 손절 2·익절 1, 추적 손절 2)은 `research/search/`와 같습니다. 최대 48봉 보유.
- 조합: 7 × 2 × 5 = **70개.** 코인 7개.
- 구간: 고르는 구간 2021-08 ~ 2024-06, 확인 구간 2024-07 ~ 2026-09. 데이터가 없는 기간은 신호가 없습니다(자료 시작일은 결과 문서에 적습니다).
- 판정은 `research/search/PREREG_SEARCH.md` 4절과 같습니다.
  - 고르는 구간: 거래 100건 이상, 평균 > 0이고 70개 전체 BH(q = 10%) 통과, 과반·최소 4개 코인 플러스, 앞·뒤 절반 모두 플러스
  - 확인 구간: 평균 > 0, PF > 1, 4개 이상 코인 플러스
  - 둘 다 통과하면 paper 후보 (최대 5개)
- 보고 항목도 같습니다: 승률, 손익비, PF, 낙폭, 두 분 방식 계좌 흐름(20배 격리 청산 반영), 가능한 최대 레버리지.

## 5. 청산 데이터 (별도)
바이낸스 공개 자료의 청산 스냅샷이 충분한 기간 있으면, 청산이 몰린 뒤 되돌림 가설을 **데이터 범위만 확인하고 결과를 보기 전에** 따로 사전 등록합니다. 없으면 서버에서 실시간으로 모읍니다.
