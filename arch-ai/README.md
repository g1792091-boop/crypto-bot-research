# 건축설계 AI 스튜디오

설치 없이 브라우저에서 실행되는 건축 설계 대시보드입니다. `index.html`을 더블클릭하거나 GitHub Pages 등에 올리면 바로 동작합니다.

## 기능

- **말로 설계**: "대지 60평에 2층 단독주택, 방 3개, 박공지붕, 레빗으로 줘"처럼 말하면 3D 모델, 층별 평면, 인테리어(가구 배치)를 만듭니다.
  - claude.ai 아티팩트에서 열면 Claude가 요청을 해석합니다.
  - 그 밖의 환경에서는 내장 규칙 엔진(평수·층수·용도·방 개수·스타일 키워드)이 동작합니다.
- **법규 체크**: 용도지역별 건폐율·용적률 한도(국토계획법 시행령 기준)와 비교합니다. 지자체 조례로 한도가 더 낮을 수 있습니다.
- **보기 모드**: 외관, 인테리어(층별 단면), 2D 평면도(치수·면적·평 환산)
- **경매·부동산 알림**: 지역·종류·최저가·할인율·토지면적 조건으로 물건을 걸러 줍니다. "이 땅에 설계"를 누르면 그 부지 크기와 용도지역에 맞춰 설계가 바로 생성됩니다. 기본으로 들어 있는 물건은 예시 데이터이고, 실제 물건은 직접 추가하면 됩니다.
- **내보내기(ZIP)**:
  | 프로그램 | 형식 | 내용 |
  |---|---|---|
  | Revit | `.ifc` (IFC4) | 층, 벽(IfcWall), 슬래브, 실(IfcSpace) |
  | AutoCAD | `.dxf` (R12) | 층별 평면(WALL/ROOM/WINDOW/DIM 레이어) + 3D 매스(3DFACE) |
  | SketchUp | `.dae` (COLLADA), `.obj` | 재질 색상과 가구가 포함된 3D 모델 |

  설계 조건 JSON도 함께 저장되며, 이 파일을 다시 불러올 수 있습니다.

## 파일

- `app.html` – 아티팩트용 원본(문서 골격 없이 작성)
- `index.html` – 브라우저에서 바로 여는 독립 실행 버전

## 한계

- 매스·기획 검토용 초안입니다. 인허가나 시공 도면으로 쓰려면 건축사의 검토가 필요합니다.
- 법원경매·온비드는 공개 API가 없어서 실시간으로 수집하지 않습니다.
- 공사비는 ㎡당 단가로 계산한 대략적인 추정치입니다.
